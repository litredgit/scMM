# 暂缓的轨迹方法与 R2/Q2：如何决定后续方向

[返回工作台说明](13-workbench.md) · [待办清单](12-upstream-todo.md)

这些问题来自上游快照 f961809；本轮没有把对应实现引入维护版。
现有 Palantir/轨迹 Python 接口继续保留。这里根据交付源码实际计算解释，不仅按按钮名称判断算法。

## 四种上游“伪时间”实际做了什么

| 上游选项 | 实际计算 | 需要决定的问题 |
| --- | --- | --- |
| diffusion / DPT | sklearn SpectralEmbedding 后，计算每个点到根点的欧氏距离 | 是否只需要这种探索性距离？不能仅凭 DPT 标签认定符合你期望的参考方法 |
| graph / kNN geodesic | 在欧氏 kNN 图上计算从根出发的最短路径 | 断连分量如何处理？根以外分量保留缺失、分别指定根，还是拒绝分析？ |
| PCA pseudotime | 标准化后取 PC1，计算到根的绝对差 | 根两侧被折到同一方向，是否符合单向过程假设？它本身不表示分支命运 |
| PAGA-like / cluster graph | 簇中心间最小生成树的距离，再加细胞到本簇中心距离 | 根定位、簇内方向和分支次序如何定义？当前加法并不保证指定根是起点 |

具体复现：一维 X 为 `[0,2,4,10,12,14]`，前三点与后三点分别成簇，指定第一个细胞为根。
上游 cluster graph 输出约 `[0.167,0,0.167,1,0.833,1]`：指定根不是 0，第一簇中心反而为 0。
这不是只修改一个标签就能解决的问题。直接减去根的数值会产生负值，强行截断又会把不同位置压成
同一时间，因此需要先明确根、方向和簇内排序的定义。

另一个已知问题是重复坐标时按“去掉第一邻居”排除自身可能失败。本轮并未导入该邻居实现，
维护版继续使用明确 `include_self=False` 的邻接构建，并补充重复点回归；这不等于上述轨迹已获验证。

### 可选方向

1. **继续只保留维护版现有轨迹接口**：改动最少；先用有时间/阶段标签的真实数据验证实际需求。
2. **只引入明确命名的实验性图距离**：称为“根点 kNN 图距离”等，不沿用容易误解的成熟方法标签；
   必须明确断连处理、根选择和输出缺失值规则。不能自动解释成真实生物时间。
3. **按指定参考实现重新开发**：先确定你要复现的论文/软件及输出语义，再确认依赖和测试基准。
   这是重新实现，不是把当前上游几行距离计算修到能运行就算完成。

建议继续暂缓，先回答：实验主要是单一连续过程还是多个分支？是否有可靠的起始细胞/阶段标签？
输出只用于探索排序，还是用于后续定量结论？没有这些约束，选择不同定义会改变科学解释。

## 上游 R2/Q2 的定义

位置：上游 `scMM/analysis/supervised.py` 的 `model_qc`。
它把类别转换为 one-hot 指示矩阵 Y，把模型输出类别概率作为预测 P，计算 sklearn 的
`r2_score(..., multioutput="variance_weighted")`。

- R2：使用训练集上拟合模型的训练概率，属于样本内结果。
- Q2：使用训练集交叉验证的 out-of-fold 概率；不是独立 holdout 测试集结果。
- 两者评价的是**类别概率对标签的拟合**，不是 m/z 特征矩阵 X 的解释方差。
  本轮不能把它们不加限定地标成用户可能期待的 PLS R2X、R2Y 或其他 Q2 定义。

在每类均出现的正常情形，它们相当于：

```text
1 - Σ(标签指示值 - 预测概率)² / Σ(标签指示值 - 训练集该类比例)²
```

Q2 只是把预测概率换成 OOF 概率。负值意味着在该归一化标准下，比常数类别比例基准还差；
训练 R2 高也不说明对独立样本有良好泛化。多类使用方差加权，不能混同于当前界面无权宏平均的 Brier。

### 为什么不直接移植

1. **名字需要澄清**：按钮只写 R2/Q2 容易使人误以为是另一套 PLS 模型指标。
2. **验证单位必须一致**：上游是细胞级随机 CV，维护版还需保留按样本/批次分组；
   即使计算公式正确，细胞泄漏也会使结果乐观。
3. **上游重复拟合**：先 cross_validate，再 cross_val_predict，进行了两轮完整 CV。
   未来如做 OOF，应在同一轮分组 CV 中同时产生指标和概率，继续保持失败即报错。
4. **已有清晰诊断**：当前已有 holdout ROC、PR/AP、Brier 和校准曲线。
   概率 R2/Q2 主要增加相对基准的误差表达，不能替代这些独立测试诊断。

### 可选方向

- **不新增**：继续用现有诊断，最省维护和解释成本。
- **明确改名后新增**：例如“训练类别概率 R2”和“分组 OOF 类别概率 R2”，记录基准、加权、
  折划分和预测来源；不写成泛指的 PLS-Q2。仍需你确认是否有实际报告需求。
- **实现你指定的 PLS 验证指标**：先确定响应编码、缩放、分母、CV 方案及参考定义，另立开发任务。

建议在没有明确报告或复现要求前继续暂缓；若需要新增，优先选择定义明确的命名及单轮分组 OOF，
而不是原样沿用上游命名和训练流程。
