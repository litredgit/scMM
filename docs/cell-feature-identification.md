# 从原始谱到细胞与特征矩阵：判定、保留与人工核对

本文面向需要理解或复核 scMM 处理方法的同行，完整说明一个细胞事件和一个 m/z 特征
如何进入最终矩阵。这里的“确认”包括算法判定与人工审核，不代表通过质谱信号单独证明
每个事件都是单个完整细胞，也不代表给 m/z 峰完成了化合物鉴定。

## 1. 输入、输出与证据

输入为按采集时间排列的 MS1 profile 谱，支持 mzML、mzXML 和 Thermo profile RAW。
RAW 通过外部 reader 读取；centroid RAW 明确拒绝，不在失败后隐式转换文件。
原始文件仅引用，不复制到项目，因此保存项目不能代替原始文件备份。

处理的主线为：

```text
原始扫描谱
  → 汇总谱、候选特征峰和共同 m/z 轴
  → 每次扫描匹配候选特征，得到“扫描 × 特征”信号
  → 参考离子判定连续细胞窗口，选择事件峰顶时间
  → 在每个窗口内计算每个特征的代表强度和检出状态
  → 按零值比例保留特征，得到逐样本“细胞 × 特征”矩阵
  → 人工审核样本并纳入，建立当前矩阵与预处理起点
  → 可选质控筛选、归一化、插补等，形成用于分析的矩阵
```

至少保留以下证据：原始文件身份与采集方法、参考离子及选择依据、实际提取参数和算法版本、
原始参考离子曲线及检测窗口、逐样本提取结果、审核纳入范围、预处理历史和最终矩阵。
若论文报告筛选后的细胞／特征数，应同时报告提取结束及每次筛选后的数量。

网页表单是草稿；正式提取使用已应用到项目／样本的参数。预览使用表单参数，
因此预览与正式提取不一致时，应先核对实际生效参数，不能只记录屏幕上的草稿。

## 2. 先选择参考离子

参考离子的作用是识别细胞经过所产生的时间事件。它不要求与每个最终分析特征属于同类分子，
也不自动将所有检测峰解释为细胞。

选择依据应包含：细胞样本中稳定且可检出的响应、空白／背景中的响应水平、质量误差和
随时间的稳定性。避免仅因为某个离子最强就将其作为参考。参考离子必须由实验者明确指定，
本文不提供适用于所有实验的固定 m/z 或阈值。

先对标准品、空白或已知细胞样本查看参考离子提取离子流（EIC），核对尖峰是否与预期事件一致，
是否存在持续高背景、漂移、饱和、连续平台或周期性仪器干扰。仅凭总离子流 TIC 的波动
不能证明当前参考离子能够区分细胞和背景。

## 3. 如何形成候选特征峰

### 汇总谱与噪声筛选

在设定的提取 m/z 范围内，程序按分辨率和重采样密度建立谱轴，并汇总扫描谱。
汇总谱用于寻找候选特征位置，不能将汇总强度直接当作单细胞强度。

汇总谱去噪先沿 m/z 方向估计局部分位数基线，扣除后得到净信号。局部噪声使用
`1.4826 × MAD`，MAD 是局部残差相对于其中位数的绝对偏差中位数；噪声下限为 `1e-12`。
净信号与噪声之比低于 `ms_peak_snr_threshold` 的点被置零，默认不保留负净信号。
在此基础上进行峰检测和质心表示，再限制在提取质量范围内，形成候选 m/z 列表。
峰检测还受实际入口传入的分辨率、峰间距和 prominence 等选项影响。

这里的汇总谱 SNR 与后述细胞事件参考信号／基线比，以及 `snr_v1` 的单细胞特征 SNR，
是三个不同的判断，不能互相替代。

### 多样本共同特征与独立特征

共同特征策略先汇总所选输入的谱信息，建立共同候选轴，再对各文件提取；一个特征成为共同轴
候选，不等于它在每个样本或每个细胞中都被检出。各样本后续仍按自己的信号进行细胞判定和
特征定量，并可能在提取阶段移除零值比例过高的列。

独立策略为各样本单独发现候选峰，再按合并策略及 ppm 容差建立最终轴。
采用并集时，某样本未匹配到的特征可以表现为零值；采用参考轴时，只保留参考轴范围内的特征。
报告多样本结果时，应说明使用哪种特征策略及合并容差，不能把“未进入候选轴”解释成
“已经检测但该细胞没有此分子”。

### 每次扫描如何对应到候选轴

各扫描中的谱峰匹配到最近且在 ppm 容差内的目标特征。误差以目标质量为分母：

```text
ppm_error = |实测 m/z − 目标 m/z| / 目标 m/z × 1,000,000
```

超过容差的不匹配；恰好等于容差允许匹配。若一个扫描的多个谱峰匹配到同一目标列，
按实际对齐聚合选项处理；常规默认取最大强度，显式 `sum` 才求和。
不要将邻近候选峰自动视为同一个分子；增大容差可能混合近邻峰。

提取范围与页面显示范围相互独立。缩小图上的 m/z 显示范围不会重新筛选矩阵特征。

## 4. 如何判定细胞事件与时间

### 两种提取算法共同的窗口原则

程序沿时间方向对参考离子信号估计基线，逐扫描判断参考信号是否通过阈值。
连续通过条件的扫描构成一个窗口；中间扫描未通过会分开窗口。
当前过程不额外用形态学操作将邻近窗口自动连接，也不将窗口内部的每一个局部峰自动拆成细胞。
因此，持续高平台可能成为一个长窗口，紧邻细胞可能合并，短暂背景尖峰也可能成为事件。

只有提取成功并人工审核纳入后，事件才进入当前数据集。审核应结合曲线与实验信息，
不能以“算法产生了一行矩阵”代替细胞事件的质量判断。

### `legacy`：单参考离子的信号／基线判断

在已对齐的候选特征中选择离指定参考 m/z 最近的一列；此路径不使用 `snr_v1` 的
`reference_ppm_tol` 参考匹配检查，须人工核对实际选中的参考质量。
设参考信号为 `R(t)`、时间基线为 `B(t)`，扫描须满足：

```text
R(t) > cell_snr × B(t)
若 cell_min_signal > 0，还须 R(t) − B(t) > cell_min_signal
```

等于阈值不通过。`cell_snr` 在这里是相对基线倍数，不是以噪声标准差定义的 SNR。
窗口内参考离子原始强度最大处为事件峰顶；若并列，选择最先出现的位置。

### `snr_v1`：多参考离子的窗口与独立特征 SNR

每个指定参考离子须在 `reference_ppm_tol` 内找到候选轴上的匹配列；没有匹配会报错。
每条参考曲线分别计算 `R(t) / max(B(t), eps)`，与 `cell_snr` 严格比较，
并在启用时同时检查扣基线净信号严格大于 `cell_min_signal`。

多参考离子的 `union` 表示任一参考通过即可；`intersection` 表示所有参考同时通过。
窗口峰顶取各匹配参考信号／基线比的平均得分最大位置，仍按最先出现位置处理并列。
这里的参考比值依然不是单细胞特征的噪声 SNR。

### 时间与扫描字段的含义

| 字段／概念 | 如何确定 | 不能据此推断 |
|---|---|---|
| `rt` | 事件峰顶对应扫描的保留／采集相对时间，单位秒 | 刺激后的实验时间或生物学阶段 |
| `cell_apex_scan` | 峰顶扫描的源索引 | 行号或跨文件通用索引 |
| `cell_start_scan`、`cell_stop_scan` | 连续事件窗口两端源扫描索引，含端点 | 额外外扩的背景区间 |
| `cell_start_rt`、`cell_stop_rt` | 窗口两端扫描的时间，单位秒 | 每个特征各自达到峰顶的时间 |
| `cell_scan_count` | 进入窗口的已选扫描数，含两端 | 原文件所有 MS 层扫描数 |
| `acquisition_time`（存在时） | 文件采集起始时间加峰顶 `rt` | 自动校正过的跨仪器实验时钟 |
| `time` | 装载入口建立的归一化时间，提取时继承峰顶行 | 默认的秒、分钟或真实实验时间 |
| 实验时间 | 用户依据实验记录提供 | 程序能从信号自动确定 |
| 伪时间 | 分析方法在指定输入上估计 | 直接测得的真实采集时间 |

源扫描索引可能因只选 MS1 而不连续，应结合源文件身份使用。
原始文件改变后不能复用旧扫描索引。旧结果若缺少窗口字段，只能报告已有证据，不能补称窗口已验证。

单文件原始装载的 `time` 是扫描 `rt` 除以该文件被装载扫描的最大 `rt`，之后提取继承峰顶值；
旧目录汇总入口可根据文件时间戳和全目录时间跨度归一化。不能跨入口假设归一化时间等同。

## 5. 如何计算细胞内特征强度并保留特征

### `legacy` 的代表强度

每个细胞窗口、每个特征分别取窗口内的原始最大强度 `M`，再与窗口内该特征基线的
统计量 `B_window` 比较，常规默认统计量为中位数：

```text
若 M > peak_snr × B_window，输出 M；否则输出 0
```

这里输出的是通过门槛的原始最大强度，不是净峰高、积分面积或所有特征在参考峰顶那一帧的强度。
不同特征可以在同一细胞窗口的不同扫描达到最大值。

### `snr_v1` 的代表强度

先对各特征沿时间扣基线，使用细胞窗口外的背景残差估计局部噪声。
局部背景点不足或方差无效时，回退到背景残差的整体标准差；背景不足时使用整体残差标准差，
并设正噪声下限。此处不是汇总谱的 MAD 噪声估计。

每个窗口、每个特征取扣基线后最大处的非负净强度 `H`，除以该处噪声得到 SNR：

```text
SNR = H / max(该处噪声, eps)
若 SNR >= feature_snr_threshold，输出 H；否则输出 0
```

等于特征 SNR 阈值通过。保留的 SNR 矩阵与强度矩阵逐项对应。
`legacy` 与 `snr_v1` 的强度定义和阈值边界不同，不能仅改方法名称后混合解释或直接比较数值。

### 提取阶段的特征保留

完成逐细胞定量后，计算每个特征在该样本细胞中的零值比例。
零值比例 `<= max_zero_frac` 的列保留，超过阈值的列移除；此阶段先于样本审核和网页质控筛选。
零值可能表示该特征未通过定量阈值或未匹配，不能直接等同于生物学不存在。

### 后续质控筛选与其他处理

网页质控先按当前矩阵的总强度及正值特征比例筛选细胞，再在保留细胞中按正值检出比例筛选特征。
阈值相等时保留；这里的特征检出比例分母是本次保留的细胞数，而非原始扫描数。
若先插补再筛选，检出比例可能已受插补影响，应按实际操作顺序解释。

归一化、插补和手动裁剪属于后续矩阵处理，不重新判定原始事件窗口。
网页注释及同位素标记保留候选证据，不等同于已经执行 Python/Notebook 的删峰式去同位素。
精确质量候选注释也不能代替标准品、MS/MS 等进一步鉴定。

## 6. 一个小型判定示例

以下数字仅解释运算，不是建议实验参数。
某参考曲线五个扫描的信号为 `[2, 12, 15, 11, 2]`，假定基线均为 `2`、
`cell_snr=5` 且关闭额外净信号门槛，则中间三个扫描严格大于 `10`，形成一个窗口。
`legacy` 的参考峰顶是强度为 `15` 的第三个扫描，事件 `rt` 来自该扫描；窗口包含第二至第四扫描。

若窗口内某特征的最大原始强度为 `20`，窗口基线中位数为 `4`、`peak_snr=3`，
则 `20 > 12`，`legacy` 输出 `20`。若另一个特征恰好为 `12`，则输出零。

对 `snr_v1`，若某特征净峰高为 `8`、该处估计噪声为 `2`，则 SNR 为 `4`；
`feature_snr_threshold=4` 时仍检出并输出净强度 `8`。

假设一个特征在 10 个已提取细胞中有 9 个零值，零值比例为 `0.9`；
当 `max_zero_frac=0.9` 时该列保留。后来若质控只留下 5 个细胞，网页特征检出率会在这 5 个中重新计算。

## 7. 人工复核的操作与判断

1. 在“原始谱与参数”核对参考离子、提取范围、方法及已应用参数，查看全程和局部 EIC。
2. 生成检测预览，查看参考曲线、基线和窗口，抽查低响应、强响应、相邻事件及长平台。
   用空白对照判断背景是否也触发相同规则；基线长期接近零时特别核对绝对净信号门槛。
3. 核对峰顶 `rt` 与源扫描，并检查窗口覆盖范围；必要时比较窗口内各扫描谱与峰顶谱。
   最大响应不能证明窗口只包含一个细胞，长窗口和相邻峰需要实验者判断。
4. 抽查若干保留峰与临界未保留峰：原始质量位置、ppm 匹配、窗口内强度、对应基线／噪声和检出比例。
   当前常规输出不保证保存每个被移除候选的逐项解释；需要完整逐峰审计时，应保留原始输入、
   实际参数和诊断数据，必要时通过离线调试输出复算，不声称界面已有不存在的审计表。
5. 在“提取审核”核对逐样本细胞数、特征数与异常，显式选择纳入样本，再建立当前矩阵。
6. 在预处理页对比筛选前后细胞／特征数及 QC，主动保存项目；重新打开完整项目应恢复所保存的矩阵和起点。
7. 发布结果时，将图中细胞、特征和范围与导出的原始作图数据对应起来。
   热图分组筛选、均值、行标准分、聚类和色阶只描述展示，不能当作新的事件识别或化合物鉴定证据。

## 8. 同行复现时应报告什么

| 内容 | 最少记录 |
|---|---|
| 输入 | 原始格式、采集方法、原始文件身份与时间依据 |
| 特征轴 | 提取范围、分辨率、重采样密度、汇总谱去噪和峰检测参数、共同／独立策略 |
| 质量匹配 | ppm 容差、扫描内聚合方式、样本间合并策略 |
| 事件判定 | 实际匹配参考离子、方法、时间基线窗口、倍数阈值、净信号门槛、多参考组合规则 |
| 特征定量 | 原始最大强度或净峰高、对应阈值与噪声定义、零值比例门槛 |
| 人工审核 | 纳入／排除样本、判断依据与限制，不把自动通过写成人工验收 |
| 后续处理 | 筛选、归一化、插补、去同位素等的实际顺序和参数，处理前后数量 |
| 分析与图 | 强度层、分组和生物重复单位、作图子集、聚合权重、标准分、聚类、色阶及随机 seed |

面向 MetaboAnalyst 的下载 CSV 为细胞行、特征列，首列 `Sample`、次列 `Label`（来自 `group`）。
它不包含完整的窗口与处理证据，不能代替项目快照、细胞元数据和原始谱。
单细胞数量不是生物重复数量；统计时仍须考虑样本／个体来源及处理泄漏。

操作查[工作流程](workflow.md)，持久化与导出格式查[数据与输出](data-output.md)，
分析解释查[分析](analysis.md)。
