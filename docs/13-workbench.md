## 启动、云盘和 Windows 路径

```sh
uv run --locked scmm-ui --config workbench.json --port 5006
```

也可用环境变量 `SCMM_UI_CONFIG` 指定 JSON；命令行 `--config` 优先。启动默认只监听
127.0.0.1；开放给其他设备仍按 [部署说明](09-web-ui.md) 配置网络和存储边界。

Linux 上 `/home/crs/data` 存在时自动显示为“云盘”。可读取其中原始文件、旧结果目录及 H5AD；
只有明确选择保存位置并确认后才保存分析结果，不自动写回输入文件。
2026-09-24 检查时该路径是只读网络挂载：程序不会修改系统挂载，实际保存需先由管理员改为可写。
可写性、硬链接/原子发布能力及中断恢复还需在实际云盘上验证；保存失败会明确报错，不改为覆盖写。

Windows 采用服务端本机路径，不是浏览器上传；例如在 Windows 主机上运行：

```powershell
uv run --locked scmm-ui --storage "云盘=D:\实验数据" --output "处理结果=D:\scmm-results" --config workbench.json
```

路径须已存在并可访问。Linux 服务器不能直接读取 Windows 浏览器电脑上的 `C:\...`；
请使用服务器已经挂载的目录。Windows 最小模式允许读取、预览和分析，明确禁用尚未适配的
后台提取任务，不以缺少 fcntl 为由阻止整个模块导入。没有新增 Windows 安装器、启动脚本或
全局线程池补丁；本轮没有 Windows 实机验收。

## 八个页面

| 页面 | 用途 |
| --- | --- |
| 数据与处理 | 读取旧结果/H5AD；设置提取参数、查看帮助、预检并提交 Linux 后台任务 |
| 原始数据预览 | 缓存 TIC、多 EIC、分箱合并谱、单扫描谱、细胞窗口与参考峰顶 |
| 预处理与 QC | 归一化、零值插补、细胞/特征筛选、异常值处理、历史层恢复、重置和按文件 QC |
| 降维与聚类 | 明确选择 X/obsm 输入；PCA、UMAP、t-SNE、Isomap、LLE；聚类与着色 |
| 差异分析 | 两组全特征检验、全局 FDR 火山图、小提琴/箱线展示、各簇 Marker 和特征相关网络 |
| 监督分析 | 分组 holdout/CV、可选 SMOTE、ROC、PR/AP、校准、Brier、适用模型的潜变量及 SHAP |
| 结果 | 当前矩阵/统计表/网络边/SHAP/监督报告下载；经确认保存包含历史层、嵌入和来源的 H5AD |
| 任务与日志 | Linux 持久任务状态、分阶段进度、日志、质量检查、审核保存和放弃临时结果 |

左侧浏览器只选择原始谱；处理结果从数据页的独立浏览器/路径框读取。
也可把当前成功完成的后台任务直接载入分析，不需要先永久保存。
后台提取任务可跨浏览器会话恢复；分析工作数据、模型及未保存历史属于当前会话，刷新页面会丢失。

旧目录若含 pickle，必须明确勾选信任后才读取，不能对不可信文件这样操作。
H5AD 不通过 pickle 导入模型。原生路径、相对路径和子文件软链接均受存储目录边界约束。

## 外部 JSON 默认值

```json
{
  "processing": {
    "ref_mz": 734.5929,
    "mz_min": 100.0,
    "mz_max": 1000.0,
    "extraction_method": "snr_v1",
    "reference_mz": [734.5929, 760.5851],
    "reference_mode": "union",
    "baseline_filter_size": 51,
    "feature_snr_threshold": 3.0,
    "feature_block_size": 256
  },
  "analysis": {
    "normalization": "total",
    "reduction": "pca",
    "n_components": 2,
    "n_neighbors": 15,
    "perplexity": 30.0,
    "random_state": 42,
    "model": "logistic",
    "cv": 3,
    "calibration_bins": 10
  }
}
```

只覆盖明确写出的键，省略项使用后端默认值。未知节/键、错误类型、非法枚举、非有限数值和
互相矛盾的范围在启动时明确失败，不静默忽略。设置的是新会话默认值，不自动加载数据或执行分析。
完整处理键与帮助以 `scMM/application/parameters.py` 为准；analysis 键也在同一模块定义。
更改文件后重新启动服务才能应用；界面手工更改不会写回 JSON。

`cell_snr` 是参考信号/基线比值；legacy 的 `peak_snr` 与 snr_v1 的
`feature_snr_threshold` 含义不同。界面展开“参数含义、单位与算法差异”可查看全部解释。
手动选择“灵敏/严格”等预设会重新设置相应阈值，实际生效值以控件和任务清单为准。

## 结果生命周期和预处理历史

- 每份载入数据有独立 ID；每次变换/筛选/派生写回递增修订号。
- 数据切换或矩阵变更使旧模型、统计表和派生图失效；相关下载禁用并清空旧下载缓存。
  分组、数据层或模型参数改变时，对应结果同样失效，必须重新运行。
- 归一化、插补等先在副本执行，通过校验才提交。失败不会留下半完成的矩阵或历史。
- X 是当前版本，`layers["scmm_input_..."]` 保存原始输入，后续每次变换写入独立历史层。
  `feature_snr` 仍是原始检测证据，不会随归一化重算，也不等同于预处理历史。
- 筛选会同步裁剪所有层；当前 H5AD 只保留当前轴的数据。会话内“重置”为本次载入时的完整
  副本，可恢复删去的细胞/特征。关闭页面后若未保存完整版本，不能仅凭筛选后的 H5AD 找回这些行列。
- X 变更清除嵌入、图及工作台生成的簇/潜变量标识。原始导入的注释保留为源数据注释。
- 历史、参数和结果摘要位于 `uns["scmm_workbench"]`；H5AD 保留已有 raw 和其他层。
  `reports_json` 保存当前差异、Marker、相关网络节点/边、SHAP 和监督摘要，不保存可执行的拟合模型；
  重新打开后如需模型操作必须重新训练，保存的报告作为历史记录保留而非恢复成当前可操作结果。
- 保存默认拒绝覆盖；改数据、改输出位置或文件名后，必须重新确认保存。程序不会删除此前已保存的文件。

保留输入、副本和每一步 layer 会占用额外内存。当前分析与细胞预览是完整计算，不是抽样近似，
大数据可能耗时；这些交互计算尚非可恢复后台任务。生产提取仍使用原有独立后台任务。

## 图与统计解释

火山图和小提琴图消费同一份全特征比较结果。选择一两个特征不会重新缩小 BH 校正的检验族。
“隐藏零值”只影响小提琴图显示，均值、fold change、p 值和 FDR 不变；每次最多展示 12 个特征。
差异检验要求非负丰度，并以细胞为统计单位；需要生物重复推断时先在上游按重复汇总。

Marker 使用当前分组列，逐簇对其余已标记细胞比较；每个比较内对全部特征做 BH-FDR，
不是跨簇联合校正。分组列、检验方法或数据层改变会清除旧 Marker。
相关网络使用所选数据层，按方差选取前 N 个特征，再计算 Pearson/Spearman/Kendall 相关。
阈值作用于绝对相关系数，边保留正负号；常数特征相关为 NaN、不连边，孤立节点仍显示。
网络不是因果图、细胞邻接图或轨迹；完整相关矩阵保留在本次会话，导出报告记录节点和阈值后边表。

降维输入是明确选择的 X 或 obsm，不自动偷偷替换成 PCA。已有输出键不能被工作台静默覆盖。
邻居数、维数或 perplexity 不适合当前样本数时会报错，需手动调整。

监督分析按所选独立样本列划分训练/测试和 CV；不选时是细胞级划分，可能存在泄漏。
全数据插补/选特征引入的泄漏不能靠分组划分自动补救。潜变量仅对 PLS-DA 和支持 transform 的
LDA 开放；lsqr 仍可做分类。未标注细胞的潜变量为 NaN，额外保存 train/test/unlabeled 标识。
AP 不标为梯形 PR AUC，Brier 宏平均定义和校准诊断说明见 [分析说明](05-analysis.md)。

SHAP 复用已训练模型及其训练折拟合的预处理：背景抽自训练集、解释样本抽自测试集，
可通过 `shap_background`/`shap_samples` 调整上限，种子沿用 `random_state`。
显示与导出跨样本（多输出时再跨类别）的平均绝对 SHAP；图展示前 30 项，CSV 包含全部特征。
这不是效应方向或因果贡献，不同模型输出空间的 SHAP 数值不能直接横向比较。
更改模型参数或重新训练会清空解释；只改 SHAP 参数会清空解释但保留模型。
SHAP 需要 supervised 可选依赖，缺失时明确报错，不自动安装；通用解释器在高维数据上可能较慢。

## 原始谱与正式提取

单扫描采用整个原始实验中的绝对索引（从 0 开始），显示实际 MS level 和秒制 RT。
多个 EIC、单谱和细胞预览复用已加载实验，不重复读盘。改文件或参数后旧预览失效。
参考峰顶是用于细胞定位的参考峰顶，不等于每个特征各自的扣基线峰顶。

图形显示的 m/z/RT 范围与正式提取参数分离。正式 `mz_min`/`mz_max` 控制合谱网格和公共特征中心范围，
对齐到这些中心时仍使用 ppm 容差；范围两端包含。默认 100–1000，所有参考须在此范围内。
细胞预览与正式单文件提取使用同一套参数及完整 MS1 扫描，不使用图形裁剪范围。

CLI 与 Python 也可指定正式范围：

```sh
scmm-process sample.mzML results --ref-mz 734.5929 --mz-min 500 --mz-max 900
```

```python
from scMM.file.data import CyESIData

data = CyESIData.load_from_file("sample.mzML", ref_mz=734.5929, mz_range=(500.0, 900.0))
```

尚未新增浏览器 RAW 上传/转换入口，现有 Python/CLI 的厂商 RAW 转换能力保持不变。
