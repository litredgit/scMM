## 数据检查与数据编辑

数据检查显示观测与特征数量，检查非有限值、全零行列、重复 ID 和缺失分组。仅特征表显示缺少定量观测提示。数据编辑提供样本名称、分组、来源个体与批次，特征显示名称和既有筛选标签。特征按稳定 ID 匹配，显示名称支持 ID／名称搜索及已命名／未命名筛选，每页最多 10 项，跨页修改可一起应用。样本与特征名称修改分别保留修改前后记录，更新对应恢复起点。同一来源含不同观测分组时，编辑来源名称会保留各观测分组。定量矩阵使用固定随机种子抽取最多 10 个观测，按完整当前矩阵的特征总强度选择前 10 项；有负值时按绝对值总和排序并标明依据，数值只读。完整矩阵从结果或当前矩阵摘要下载。

## 预处理与 QC

在「预处理」依次选择异常值处理、筛选、零值插补、归一化或标准化。应用筛选后默认转到归一化，仍可手动返回插补。在候选数据上点击「检查影响」，核对轴大小、各样本的细胞数和 QC，再点「应用到当前数据」。变换后依赖旧矩阵的结果需重新计算。「历史与恢复」可定位对应层和完整预处理起点。

QC 总强度和检出特征数读当前矩阵，参考信号沿用提取记录。归一化后的非零总量可能仅在浮点误差范围内偏离 1，零总量显示为 0。经过插补、对数或标准化后，强度大于 0 的计数含义随数据空间而变。

每个指标单独一行，统计列为 mean/median/std/min/max；cell_count 是样本实际细胞数，不是参考强度非空值数。
参考强度指标名称包含 m/z；不同参考离子保留独立行，仅省略该样本没有有效值的参考强度记录。
参考强度来自提取时的原始记录，不随当前 X 的归一化或插补重算；总强度和检出特征数反映候选矩阵。

“添加筛选标签”默认收起。展开后选择“图上套索圈选”，查找并选择横纵轴变量，再点击“绘制圈选图”；图默认启用套索，按住鼠标拖动围住细胞后松开，检查选中数量，再点击“保存标签”。可以只保存标签或同时启用，多个启用标签取交集。切换数据、坐标、选择方式或重新绘图清除旧圈选；关闭全部标签恢复完整筛选前矩阵。原始信号诊断保持为可选折叠入口，详见[原始信号诊断](extraction.md#原始信号独立诊断)。

需要永久缩小当前矩阵时，使用「按稳定 ID 取子集」。至少填写一类细胞或特征 ID，以换行或逗号分隔，另一类留空会保留该轴。检查影响后再应用。完整预处理起点仍可恢复被排除的数据。

启用筛选期间可以基于筛选后的数据分析；归一化、插补、普通筛选和恢复层等矩阵变换须先关闭全部标签，或重置到预处理起点。目录项目保存完整标签恢复池；独立 H5AD 只包含当前矩阵，不能据此恢复已排除项。

#### 缺失值填补

| 内部参数 | 默认值 | 选项 | 推荐 |
|---|---:|---|---|
| `IMPUTE_METHOD` | `None` | `knn`、`mean`、`median`、`most_frequent` | 默认不填补；确认 0 表示缺失而非真实低信号后再开启 |
| `IMPUTE_OPTIONS` | `n_neighbors=5` | 传给相应 scikit-learn imputer | KNN 可从 5 开始；细胞少时不得超过有效样本规模 |

API 默认是 `impute(method="knn", missing_values=0)`。所有方法都会修改当前对象，并保留原行列索引。
KNN、mean、median、most_frequent 保留全空特征列，并将该列填为 0；不会删除特征或更改细胞/特征元数据。
`keep_empty_features` 固定为 `True`，显式传入 `False` 会报错。结果形状或有限值检查失败时保留原矩阵。

#### 归一化

内部 API 默认方法为 `total`；网页默认值见网页参数章节。

| 方法 | 主要参数及默认值 | 含义 | 使用建议 |
|---|---|---|---|
| `total` | `scale=1.0` | 每个细胞除以行总强度再乘 scale | 单细胞总信号差异明显时的首选起点 |
| `max` | `axis=1` | 除以每个细胞最大值 | 由稳定强峰主导且关心相对峰型时使用 |
| `quantile` | 无 | 使每个特征列具有共同分位数分布 | 假设多数特征分布相近；可能削弱真实全局差异 |
| `pqn` | `reference="median"` | 概率商归一化 | 代谢组常用；也可用 `mean` 或自定义一维参考谱 |
| `zscore` | `axis=0` | 按特征做标准化 | 适合降维/聚类，不再保留原始强度尺度 |
| `log` | `pseudo=1e-6` | 计算 `log1p(X+pseudo)` | 压缩高强度长尾；通常应在尺度归一化后单独评估 |
| `minmax` | `axis=0` | 每个特征缩放到 0–1 | 适合部分机器学习输入，不适合解释绝对倍数 |

注意：当前接口一次只执行一种方法。若需要“总量归一化后再 log”，必须连续调用两次，并记录顺序。

默认方向与零值处理细节（Vue 选项使用相同实现）：

| 选项 | 方向与默认计算 | 影响 |
|---|---|---|
| `total` | 每个细胞除以自身强度之和，默认 scale=1 | 非零总和约为 1，全零细胞保持 0；允许浮点误差 |
| `max` | 每个细胞除以自身最大强度 | 最大值为 1，总和不固定；零最大值按除数 1 处理 |
| `pqn` | 各特征跨细胞的中位数形成参考谱，细胞相对参考谱的商的中位数作为除数 | 商的中位数包含零值；参考值及除数为 0 时按 1 处理，不自动先做 total |
| `zscore` | 每个特征跨细胞减均值、除以总体标准差（ddof=0） | 产生负值，常量列变为 0；正值计数不再是原始检出数量 |
| `log` | 逐元素 `ln(1 + X + 1e-6)` | 自然对数，零值变成约 1e-6 的正数；影响后续 >0 计数和零值插补 |
| `minmax` | 每个特征跨细胞缩放到 [0,1] | 常量列为 0，原有正值可能变成 0，总和不固定 |
| `quantile` | 按特征列排序，目标分位数取各列相同排名的平均值；并列值取对应目标分位数的平均值，零值参与且可能变为非零 | 统一特征列的分位数分布，并非按细胞行归一化，总和不固定 |

### 预处理参数

子集操作 `subset` 的 `cell_ids`/`feature_ids` 为稳定字符串 ID 列表；至少一项非 null，显式列表不能空、重复或含未知 ID。
未选轴用 null 保留全部，所列顺序保留；不按当前表格行号或 m/z 近邻选择。该操作不做归一化或重新提取。

Vue normalization 的计算方向与零值影响见[归一化](#归一化)。选项使用同一数值实现，
每次只执行一种方法，完整说明也可在预处理页面问号及方法列表查看。
“预处理高级参数”只应用当前方法相关字段，实验参数不由界面自动选择：

| 网页/工作台字段 | 默认值 | 范围及含义 |
|---|---|---|
| total `scale` | 1.0 | 有限正数，每细胞归一化总量 |
| max/zscore/minmax `axis` | 方法默认 | max 为 1（每细胞），zscore/minmax 为 0（每特征）；可显式选 0/1，不接受布尔值 |
| PQN `reference` | median | median/mean；自定义参考向量继续用 Python `normalize`/`CyESIData.normalize`，网页不接受任意向量 |
| log `pseudo` | 1e-6 | 非负，计算 ln(1 + X + pseudo)，无定义或非有限结果拒绝提交 |
| impute `method` | median | median/mean/most_frequent/knn；0 视为缺失，全空特征保留为 0 |
| KNN `n_neighbors`/`weights` | 5 / uniform | 正整数，实际请求邻居数以细胞数为上限并记录；uniform/distance，不保证每个缺失项都有同样数量的有效供体 |
| IsolationForest `n_estimators` | 100 | 1–10000 的整数 |
| `max_samples` / `max_features` | auto / 1.0 | 整数数量或 (0,1] 小数比例，数量不能超出当前轴；max_samples 另可 auto，不允许比例选出 0 细胞 |
| `bootstrap` / `random_state` | false / 42 | 是否有放回抽样；seed 为 0–2147483647 整数 |

HTTP 子采样可传数值；为区分数量 1 和比例 1.0，网页传严格十进制字符串（例如 `"1"` / `"1.0"`），拒绝尾随字符。
应用参数写入历史 `effective_parameters` 并随项目保存重开保留，草稿仅由维护恢复保存，不等同于主动保存的已生效参数。
内部方法默认值不作为网页参数的替代依据。


`min_detected` 为检出比例：当前强度大于 0 的特征数除以本次筛选前全部特征数，范围 0–1，默认 0.2；低于阈值移除，等于阈值保留，0 关闭此条件。先按 `min_total` 和 `min_detected` 筛选细胞，再在保留细胞中计算
`min_feature_fraction`（默认 **0.2**，至少 20% 保留细胞中检出）；筛选不会重新进行峰检出或 SNR 判断。变换和插补会改变这些指标的含义。

| 参数或控件 | 网页默认 | 含义与约束 |
|---|---|---|
| 标签检出率 | 0.1 | 使用当前筛选前完整矩阵，或指定来源文件；不修改提取阶段阈值 |
| 标签异常检测 | contamination 0.05；seed 42 | Isolation Forest 标签，不视为生物学异常结论；标签组合若清空任何轴则拒绝 |

## 选择分析与核对结果

主体分析页提供「探索 / QC」和「统计比较」，包括 UMAP 和现有聚类方法。服务器启用随附插件后显示相关网络、
监督与 SHAP、伪时间与趋势的对应入口。停用插件后，已保存的有效报告和图仍可在「结果与保存」读取或下载。
计算参数初始展开并固定，可收起或取消固定。先选择强度层或输入表示，设置分组、输出键和随机种子，再显式运行。
插件扩展的主体方法在预处理、降维、聚类或差异与 Marker 的「插件方法」中选择。[服务器启用配置](deployment.md#启用插件) · [主体方法](method-plugins.md#可接入类型)

计算、刷新工作区、读取报告和绘图期间保持互斥。计算失败保留已有结果；计算已完成但后续读取/绘图失败时，
页面明确提示结果已保留，可用对应读取/更新图按钮重试；摘要异常可点击“重新读取分析状态”。
超时后先读取实际状态，不自动重放计算。应用视图设置只更新工作区，磁盘持久化仍须主动“保存项目”。
开发接入规范见[分析功能接入指南](development.md#分析功能接入指南)。

- UMAP 的 PCA 输入、火山图标注、小提琴图上限等默认值见 [分析参数](#降维聚类与统计显示参数)；非法维数明确报错，不静默截断。
- `color_source` 分别选择列标签、Feature 或无着色。列标签按原始列顺序展示，默认选择有效 group、其次 sample；
  `color` 下拉框完整列出当前可选项，可用 `color_search` 边输入边筛选，不区分大小写。
  Feature 默认按平均强度降序，可改为总/中位强度、检出率、m/z、名称及升降序；强度选项显示排序值。
  搜索支持完整 feature ID、名称或 m/z；筛选保留已选项，并显示当前/总选项数量，可点击“清除着色筛选”恢复全部。
  切换着色来源清空搜索，保留本会话各类选择。聚类成功后自动切换到列标签并选中新簇列；已有列仍可重新选择。
- “差异与 Marker”分别展示两组差异、各组差异 Marker 与分类权重 Marker。前者明确 A/B 方向、数据层、检验及全特征 BH-FDR；点击“计算两组差异并绘制火山图”完成统计并自动绘图。
- 火山图支持调整阈值、标签数量和排序，再点击“更新火山图”；这些显示操作不重新检验。绘图失败可单独重试。
- 点击火山图中的点或在“小提琴特征选择”中搜索勾选特征；搜索支持稳定 ID、m/z 及有效活动注释的候选名称。
  已选项跨搜索/分页保留，可移除、清空和上下调整绘图顺序，最多 12 项；达到上限时禁止继续添加。
  两种入口均只改变选择，点击“绘制小提琴图”后更新图形；选择或隐藏零值设置改变后显示待更新提示。

  显示选择不改变统计检验族，解释见 [分析](#统计解释与网页分析)。

  数量不足或来源标签空白时直接报错，不自动改为细胞级划分。报告显示来源/细胞计数及上游处理与重复调参提示，
  保存重开及下载仍保留解释；细胞级探索不能解释为独立来源验证。定义见[统计解释](#统计解释与网页分析)。

  PDF 是分页摘要，完整数值见附件；图的论文版式仍用逐图导出，不为报告自动计算或主动保存项目。
- 分析“探索”中的“采集稳定性 QC”须明确选择参考特征、来源、坐标含义及时间列（存储顺序除外），
  再手动生成参考强度分布、分箱数量和来源中位谱相关；完整表可下载，保存重开后可读取只读图。
- 分析“探索”中的“特征距离嵌入”接收稳定 ID 列表（空白使用全部）、层、距离、名称/类别列和 UMAP 参数，
  手动生成后下载完整坐标/距离表；保存重开可读取只读图，超出资源边界明确拒绝。
- 分析“探索”中的“双特征散点”支持搜索/分页选择两轴特征 ID、强度层及来源/分组着色；搜索保留已选 ID，
  编辑不自动绘图，点击“绘制双特征散点”执行。可选全体细胞线性回归，图旁说明常量、零值及缺失值处理。
  主动保存后可重开“读取已保存散点”，共用论文图和完整作图数据下载；失效图不可下载。
- 参数显示简洁中文名，悬停保留英文键与解释，操作按钮用中文，系统自动生成的图表文本用英文；高级分析参数及新结果名称的解释通过悬停查看。图形白底、无网格或十字线；强度及 p 值/FDR 使用科学计数法，m/z 四位小数。
  按钮颜色、参数帮助及图形显示见[Vue 帮助与图形显示](projects-and-data.md#网页帮助与按钮)，表格在自身区域滚动。

使用离子定量视图时，先核对[活动分支和输入数值空间](annotation.md#离子视图与定量空间)。差异检验的统计层与计算倍数变化的线性丰度层可分别选择。

### 统计解释与网页分析

火山图和小提琴图消费同一份全特征比较结果。选择一两个特征不会重新缩小 BH 校正的检验族。
“隐藏零值”只影响小提琴图显示，均值、fold change、p 值和 FDR 不变；每次最多展示 12 个特征。
网页小提琴图标题中的全局 FDR 与统计表中的 p 值/FDR 均以三位有效数字的科学计数法显示
（如 `1.23e-06`）；显示格式不改变检验、校正或 CSV 导出的原始精度。
差异检验要求非负丰度，并以细胞为统计单位；需要生物重复推断时先在上游按重复汇总。

Marker 使用当前分组列，逐簇对其余已标记细胞比较；每个比较内对全部特征做 BH-FDR，
不是跨簇联合校正。分组列、检验方法或数据层改变会清除旧 Marker。
相关网络使用所选数据层，按方差选取前 N 个特征，再计算 Pearson/Spearman/Kendall 相关。
阈值作用于绝对相关系数，边保留正负号；常数特征相关为 NaN、不连边，孤立节点仍显示。
网络不是因果图、细胞邻接图或轨迹；完整相关矩阵保留在本次会话，导出报告记录节点和阈值后边表。

工作台降维显式选择 X 或 obsm。UMAP 默认启用 PCA 输入（20 维），维数不足时可调整或关闭。
已有输出键不能被工作台静默覆盖；邻居数、维数或 perplexity 不适合当前样本数时明确报错。
内部调用见[统一降维入口](internal-reference.md#统一降维入口)。

网页聚类独立选择 X 或已有嵌入；DBSCAN 邻域、图聚类分辨率及常用算法参数现可显式设置，
具体白名单及各入口默认值见[分析参数](#降维聚类与统计显示参数)。聚类只新增观测标签，不变换矩阵。
DBSCAN 的 -1 为噪声，不能当作生物簇；全部噪声是允许的结果。参数、输入表示和 seed 记入处理历史，
同一输出列不能覆盖，调整参数须用新列名；保存重载保留标签与实际参数，不自动重算旧项目。

“双特征散点”使用当前矩阵或明确选择的强度层，按两个不同的稳定特征 ID 精确取值，
不沿用 内部数值质量输入的最近峰匹配。可按样本/来源/分组列着色：数值列用连续色条，
类别列用图例，缺失或非有限着色不排除其有限两轴数值。零值参与散点和回归；非有限两轴值仅从显示/拟合排除，
完整作图表仍包含其原行、稳定细胞 ID 及 `included` 标记。
可选回归是全部有限细胞的普通最小二乘 y 对 x，不按着色组分别拟合；报告斜率、截距、R²、p 值和标准误。
x 为常量或少于两个有限细胞时不拟合；y 为常量只显示常量线，不报告 R²/p/标准误；极端数值尺度无法稳定拟合时保留散点而不输出无效拟合。
仅两个细胞的拟合、细胞级 p 值和着色分组均不能替代生物重复或因果证据。
图及完整细胞/回归表随项目保存，重开可“读取已保存散点”；强度变换使其失效，修改相关来源/着色字段也须重绘。

“特征距离嵌入”对所选强度矩阵的特征列计算成对距离，再用预计算距离 UMAP 生成二维坐标。
Pearson 定义沿用 `PlotEngine.feature_network()` 的 `sqrt(2 × (1 − |r|))`，因此完全正相关和负相关均为零距离；
Euclidean 是原值欧氏距离，不暗中标准化。网页拒绝非有限输入、Pearson 常量列、全部零距离和少于三个特征；
不沿用旧绘图辅助将未定义相关距离置零的回退。每点是特征，不能与细胞降维或相关阈值网络混同，也不能推断分子鉴定关系。
选择精确 ID、输入层、var 名称/类别列；空白/缺失名称回退 ID、重名由 ID 区分，缺失类别独立显示。
为限制平方级距离/导出开销，最多 500 特征且输入数值不超过 200 万；超限先明确缩小特征集，不自动抽样。
保存完整距离表、坐标/名称/类别表及有效 UMAP 参数；固定 seed、随机初始化、单作业便于同环境重现，不承诺不同依赖版本逐位相同。

“采集稳定性 QC”将 内部绘图层的参考特征分箱检查接入网页：明确选择来源列、精确参考特征 ID、强度层、
时间坐标及其含义（采集秒数、0–1 归一化时间、伪时间或当前存储顺序）；不从行号推断采集时间。
统一等宽时间箱显示参考强度箱图与逐来源细胞数，来源按首次出现顺序保留；最大坐标纳入最后一箱。
非有限坐标细胞不参与分箱及来源谱，但完整细胞表保留排除标记和 bin=0；空窗口计数为 0、强度为缺失。
参考强度保留零值、忽略非有限值作中位数；存在非有限强度的细胞总量记为缺失，不将部分和冒充完整总量。
另计算各来源在所有有限坐标细胞中的逐特征中位谱，再跨特征算来源间 Pearson 相关；
常量谱、少于两个可比较特征或没有有限时间细胞的来源显示未定义，不置零。
全体窗口/细胞表、来源中位谱与相关表随图导出和保存重开；修改所用时间/来源列或变换矩阵使图失效。
上限为 100 个来源、100 个窗口和 200 万输入矩阵数值；超限需显式取子集，不自动抽样。
这些描述不等同于生物重复验证，不证明批次消除、信号鉴定或归一化有效。

当前数据 QC PDF 汇总当前 X 的细胞数/特征数、零值比例、来源细胞数、总强度/检出特征中位数及 40 箱分布，
并列出已有参考强度元数据摘要，不重新提取或最近质量匹配。输入和参考强度须可作有限数值汇总。
当前分析报告 ZIP 在该 PDF 摘要外保留完整 QC、处理历史、已有有效差异/Marker/网络/监督/SHAP 数值和参数，
以及当前嵌入、身份匹配图的 JSON/完整作图表；不运行缺少的分析，不序列化模型或个人 AI 内容。
PDF 分页、表头重复、中文使用 STSong-Light CID 字体；长历史、长结果和大量来源的摘要上限明确标注，附件不按摘要截断。
请求必须匹配当前数据 token；重开、变换或其他数据修订后旧请求拒绝，不能把旧快照/报告当作当前结果。
身份不能核实的旧图列入省略原因，旧只读报告本来未保留的中间数据不重算补造；论文图仍由逐图导出提供。
报告不等同于保存项目、实验准确率验收、细胞级独立验证或鉴定证明。

网页监督分析的“验证方式”默认要求独立来源字段；选择细胞级探索后可不按来源分组。
监督分析按所选独立样本列划分训练/测试和 CV；不选时是细胞级划分，可能存在泄漏。
全数据插补/选特征引入的泄漏不能靠分组划分自动补救。潜变量仅对 PLS-DA 和支持 transform 的
LDA 开放；lsqr 仍可做分类。未标注细胞的潜变量为 NaN，额外保存 train/test/unlabeled 标识。
AP 不标为梯形 PR AUC，Brier 宏平均定义和校准诊断说明见 [概率诊断](#监督模型与概率诊断)。

监督训练在拟合前检查来源组支持：分组留出再加至少两折 CV，要求每个类别至少出现于 3 个来源组；
空白来源标签报错。这个下限只是划分的必要条件，不证明生物重复充足，也不保证当前 seed、test_size 和 cv
能让训练、留出与每折均含全部类别；既有划分检查继续执行，不静默改 seed 或改为细胞级验证。
选“细胞级探索”可按现有规则训练，但报告明确标记不能解释为独立来源验证。
来源组数仅计数用户选定分组列的不同值，不自动把文件、subject、sample 等字段认定为生物重复。

诊断的 `validation_audit` 同时保存全部/训练/留出及逐 CV 折的各类细胞数和来源组数，
未标注而排除的细胞计数、输入层与强度来源、可读取的预处理步骤及解释提示；不分组时来源组数为缺失值。
记录中的插补、筛选、离群剔除及部分依赖全体数据的归一化会提示核对上游泄漏。
历史可能含其他层或已恢复步骤，报告不把所有步骤断言为所选输入的变换；切换强度层不能恢复已筛除的轴。
历史缺失/无法解析和未知强度来源不能证明没有泄漏。当前不自动重做折内插补/选特征，也不追踪所有外部调参；
反复查看留出集或据此调参后，不能再将其当作独立测试。网页直接显示提示，保存重载和 JSON 下载保留完整解释。

SHAP 复用已训练模型及其训练折拟合的预处理：背景抽自训练集、解释样本抽自测试集，
可通过 `shap_background`/`shap_samples` 调整上限，种子沿用 `random_state`。
显示与导出跨样本（多输出时再跨类别）的平均绝对 SHAP；网页图的显示数量可调（默认 20 项），CSV 包含全部特征。
这不是效应方向或因果贡献，不同模型输出空间的 SHAP 数值不能直接横向比较。
网页更改模型参数会失效旧诊断；成功重新训练会替换模型并清空解释。直接 API/工作台训练失败保留原有效模型与解释。
只改 SHAP 计算参数会清空解释但保留模型；类别/细胞/特征/显示数量属于绘图设置，不重新计算解释。
SHAP 需要 supervised 可选依赖，缺失时明确报错，不自动安装；通用解释器在高维数据上可能较慢。

### 降维、聚类与统计显示参数

分析页网络的 `layer` 独立于差异比较，默认 `null`（当前 X）；监督训练的 `random_state`
独立于降维，初始来自分析配置的 `random_state`（通用默认 42），SHAP 使用该监督 seed。
监督 `group_key` 按用户所选字段计数来源组，拒绝空白标签；分组留出及 CV 的每类来源数量要求
与解释边界见[统计解释](#统计解释与网页分析)，不会因数量不足自动改 seed 或切换验证方式。

网页聚类使用下表白名单；旧项目缺少新增字段时保留此前算法默认值，不追溯重算旧聚类。
Python 工作台 `AnalysisWorkspace.cluster()` 同样接受这些参数；内部 PlotEngine 默认值按实现定义。

| 方法 | 可调参数及网页/工作台默认值 | 合法性与含义 |
|---|---|---|
| 通用 | `use_rep="X"`、`random_state=42`、新输出 `key="clusters"` | 显式选矩阵/嵌入；输入须有限且非空，已有观测列不能覆盖 |
| KMeans | `n_clusters=3`、`n_init=10`、`max_iter=300`、`tol=0.0001` | 簇数为 2 至细胞数；初始化/迭代次数为正整数，容差非负 |
| 层次聚类 | `n_clusters=3`、`linkage="ward"`、`metric="euclidean"` | 连接方式为 ward/complete/average/single；Ward 仅支持欧氏距离 |
| DBSCAN | `eps=0.5`、`min_samples=5`、`metric="euclidean"` | 半径为正数，尺度取决于输入表示及距离；邻域样本数含自身，至少为 1；可超过细胞数并得到全部噪声 |
| Leiden / Louvain | `n_neighbors=15`、`resolution=1.0` | 邻居数为 1 至细胞数减 1；分辨率为有限正数，不等同于质谱质量分辨率 |
| Leiden | `n_iterations=2` | 正整数或 -1（至不再改进） |
| Louvain | `threshold=1e-7`、`max_level=null` | 停止阈值非负；最大层数为空时不限，否则为正整数 |

DBSCAN 与层次聚类的距离白名单为 euclidean/manhattan/cosine，不开放预计算距离矩阵。
所有数值须有限，整数不接受布尔值/小数；方法不适用的表单草稿不参与计算。
历史 `effective_parameters` 仅记录该算法实际生效的参数；修改表单不计算，点击“运行聚类”后才生成新列。
聚类仍共享降维面板的 `use_rep`、`n_neighbors` 和 `random_state`。旧项目缺独立字段时保留原先借用值，
恢复/保存操作见[分析流程](#选择分析与核对结果)，开发兼容规则见[接入指南](development.md#参数草稿与恢复)。

报告下载只读取当前 X，不另选强度层或执行分析；下载请求 `key` 必须是当前 `/analysis` 返回的 token 的 JSON，缺失/过期拒绝。
工程边界：最多 10 万细胞、500 万当前矩阵数值、累计 500 万嵌入数值和 64 MiB 作图表文本；超限明确提示逐项导出，不自动抽样。
PDF 使用 40 箱直方图，最多列前 500 个来源、200 个参考列及最后 200 步历史，长条目/结果摘要显式截断；ZIP 保留完整数值和历史。
这些是报告/显示资源边界，不能解释为实验筛选阈值或科学质量合格条件。

采集稳定性 QC 的 `source_key`、`feature`、`time_kind` 必须显式选择；`time_key` 在非 stored_order 时必须为可转数值的观测列，
不自动推断时间或参考离子。`time_kind` 可为 acquisition_seconds/normalized_time/pseudotime/stored_order；
normalized_time 的有限值须在 [0,1]，stored_order 使用当前行顺序且不接受 time_key。至少两个有限且不同的坐标。
`bins=10`，范围 2–100；`layer=null` 用 X，参考 ID 必须存在，最多 100 来源及 200 万输入数值。
缺失来源单列，不合并同名原标签；窗口及来源谱定义见[统计解释](#统计解释与网页分析)。

特征距离嵌入 `features=[]` 使用全部稳定 ID，显式列表不允许重复/缺失 ID；最多 500 项及 200 万输入数值。
`layer=null` 使用 X，`metric=pearson` 可选 euclidean，`name_key`/`class_key=null` 默认用 ID/统一颜色；指定时须为现有 var 列。
`n_neighbors=null` 使用 min(15, 特征数−1)，显式值为 2 至特征数−1；`min_dist=0.1` 范围 [0,1]，`random_state=42`。
UMAP 固定二维、`init=random`/`n_jobs=1`，预计算距离定义见[统计解释](#统计解释与网页分析)。

双特征散点 `feature_a`/`feature_b` 必须是当前数据中两个不同的稳定特征 ID，不接受自动最近质量匹配。
`layer=null` 使用当前 X；`color_key=null` 为统一颜色，否则明确选择一个观测列；`regression=true` 默认显示全体有限细胞的 y 对 x 回归。
这些网页设置与图随主动保存保留；科学定义及常量/缺失边界见[统计解释](#统计解释与网页分析)。

网页分析默认 `color_source=annotation`（列标签），优先选择有效 group、其次 sample；
可切换为 `feature` 或 `none`。Feature 默认 `color_sort=mean`、`color_descending=True`，即平均强度降序；
排序还支持 `total`、`median`、`detection`、`mz`、`name`。下拉选择与搜索的操作见[工作流程](#选择分析与核对结果)。
火山图标签默认 FDR≤0.05、abs(log2FC)≥1，FDR 优先/效应量辅助排序，最多标注前 10 个特征；阈值、数量和排序可调整。
小提琴图每次最多 12 个，默认包含零值。它们是显示设置，不改变检验和数值导出。

### 主成分、Marker 与热图

PCA 保存每个主成分和累计解释率；图中可选择已计算坐标的任意两个或三个不同维度。
三维图需要先计算至少三个维度，不能用二维结果生成不存在的第三轴。常数矩阵拒绝 PCA。
分类 Marker 使用逐组对其余组的逻辑回归，L2 正则化强度 `C=1`、类别均衡权重、随机种子 42；
每折独立拟合标准化，交叉验证最多五折并受最小类别数约束，少于两折报错。
输出全量正负权重、排名、折间均值/标准差和符号稳定性；默认展示正权重，可切换显示负权重。

所有强度显示使用两位有效数字，例如 `12345 → 1.2e+04`；m/z、比例、统计概率不套用这一格式。
计算、CSV 和作图数据不按显示精度取整。数据层只改中文显示名称，内部键保留。
热图行标准分用列间总体标准差（ddof=0），常数行显示 0；聚类用欧氏距离、平均连接和最优叶序，
不改变矩阵或下游分析。热图最多 1000 个特征、200 万色块；超过 5000 项的轴需关闭聚类或先分组聚合。

分析图中的细胞事件点可选入“细胞质谱”，最多两个，支持跨样本比较。
来源包括当前矩阵特征棒状谱、提取窗口求和/平均原始谱及峰顶单扫描谱；可切换原始/最大值/TIC 归一化，叠加/镜像。
原始来源需要有效扫描溯源及同一输入文件身份，缺少时明确提示选择矩阵谱。

热图可手填特征编号、使用所选特征、正向分类 Marker 或已注释特征。预先运行分类 Marker 后，可选择一组并载入该组最多 50 个正权重特征，按该组完整结果的排名选择。已注释特征按当前统计分支取有效测量根候选，L1 只纳入保留变量，L2 按固定代表离子映射。差异和 Marker 表支持分页，并可从稳定 ID 回看可用的测量峰。特征选择器支持显示名称搜索。作图范围可多选组别和样本，并上下移动样本顺序。
网页默认关闭列聚类：按指定样本顺序排列，样本内按峰顶 `rt` 排列，缺失时间排在该样本末尾、同时间保留原顺序；
整列缺少 `rt` 时保留样本内原始顺序。特征聚类独立控制，开启列聚类会重新排序，不再保留样本顺序。
可选择逐细胞、按样本均值或按组均值；分组均值明确选择细胞等权或样本等权。
热图先筛选作图范围，再计算均值和行标准分；色板及色阶上下限同时作用图形和导出，手动色阶的截断须在图注说明。
修改设置不立即替换成功图，点击“生成热图”后生效。下载包含所选范围的源矩阵、聚合矩阵、展示矩阵、注释和排序。
嵌入图、小提琴图、双特征散点也可筛选作图范围：嵌入沿用已计算坐标，小提琴沿用原差异检验和全局 FDR；
双特征散点回归描述选中范围内的有限细胞。火山图和监督诊断保持其分析结果范围，不能靠隐藏组别重新解释检验。

#### 作图子集的解释

热图筛选发生在聚合、标准分与聚类之前；不同作图范围的行标准分和排序不能当作同一固定数值尺度直接比较。
嵌入图筛选保留已有坐标和解释率，小提琴筛选不重算原比较的检验与全局 FDR。
双特征回归描述所选有限细胞范围；筛选后的拟合变化不是原统计结果被重新估计。
操作与导出见[论文图、细胞联动与热图](projects-and-data.md#图表作图数据和报告)，
上游事件与保留特征的方法见[细胞事件与特征峰确认流程](extraction.md#从原始谱到细胞与特征矩阵)。

`scope.groups`、`scope.samples` 为 null 表示全部，空列表报错；指定样本列表的顺序用于关闭列聚类时的排列。
样本内按 `rt` 排列；不以归一化时间或伪时间替代采集时间。筛选后的行标准分使用当前展示列的总体标准差。
色板可选 RdBu、PuOr、Viridis、Cividis；`color_min`／`color_max` 默认均为空（自动），手动时须同时为有限数且下限小于上限。
导出范围默认 `current`（当前视图），可选 `full`（本次图形完整范围）；系统图文固定英文，用户输入保留原文。
这些设置只影响作图，不改当前矩阵。Cell 规格、字体／分辨率与导出入口见[论文图操作](projects-and-data.md#图表作图数据和报告)。

| 参数或控件 | 网页默认 | 含义与约束 |
|---|---|---|
| 热图聚合 / 连接 / 距离 | mean / average / euclidean | 可选 median、sum；complete、single、ward；cityblock、cosine、correlation；Ward 仅支持欧氏距离，样本等权仅支持均值 |

## 目标相关性、数值关联与集合

目标相关性支持数值 obs 或一个稳定特征对当前矩阵全部其他特征，Pearson、Spearman 和 Kendall 均按逐对有限值计算；可显式排除任一变量为零的细胞。常量或少于 3 个有效值标为未定义，不填 0。排序、标注和图上显示不裁剪数值导出。

数值关联输出 y 对 x 的 OLS、R² 和均值响应 t 区间，置信带不是单个未来观测的预测区间。默认仅描述细胞关系，不进行置换检验。显式指定独立重复列后，对每个重复内共同有效细胞取均值，再在重复间置换 y，使用双侧绝对 Pearson r，p=(超越次数+1)/(置换次数+1)，记录 seed。重复可交换性仍由实验设计保证；文件名、处理组或细胞标签本身不证明独立性。

特征集合以每组有限强度高于阈值的检出比例判定，保留排他交集及完整成员。Venn 面积不按数量缩放；UpSet 将交集数量与成员关系一起展示。候选集合必须有当前有效脂质候选版本，以数据库 SHA-256 与记录 ID 构成身份，合并该记录的支持特征集合，保留全部映射；不能把共同名称当成已鉴定化合物。

| 参数或控件 | 网页默认 | 含义与约束 |
|---|---|---|
| 目标相关性 | Pearson；保留零值；标注 10 项 | 每个特征按有限值逐对计算，少于 3 个有效细胞或变量恒定时结果未定义；CSV 保留完整特征及 n |
| 数值关联 | 不选重复列；置换 0；置信水平 0.95；seed 42 | 置换必须选择重复单位，先按重复求均值，最多 10000 次，分析单位数乘置换次数最多 2000 万 |
| 集合检出 | 强度 > 0；组内检出比例 ≥ 0 | 至少一项检出才进入集合；UpSet 默认最多显示 30 项，完整交集不随显示上限裁剪；Venn 限 2–3 组 |

统计分析板块的“相关性与集合”提供目标变量与全部特征相关性、数值关联、Venn 和 UpSet。目标变量使用上述稳定编号或数值注释；零值是否参与由用户明确选择。数值关联选择真实独立重复列后先按重复计算均值；置换次数默认 0，不选择重复单位时只能作细胞级描述。集合可按稳定特征或当前有效版本的候选身份统计，完整成员及候选来源从图旁下载。

## 监督模型与概率诊断

独立监督分析也可直接使用 AnnData，不必创建 PlotEngine：

```python
from scMM.analysis import SupervisedAnalyzer

analyzer = SupervisedAnalyzer(adata, "condition", group_key="sample")
result = analyzer.evaluate("logistic", cv=3, calibration_bins=10)
diagnostics = result["probability_diagnostics"]
pr_curves = analyzer.precision_recall_curves()
calibration = analyzer.calibration_curves()
```

数据须提供足够的独立样本，使 holdout 和各 CV fold 均包含所有类别。
诊断仅使用 holdout，不新增训练。AP 是 average precision，不是梯形积分 PR AUC；
`brier_macro` 为每类 one-vs-rest 概率均方误差的无权平均，不是各类别误差之和。
校准曲线采用 quantile 分箱，重复/空分箱可能使返回点数少于 calibration_bins；
这只是可靠性诊断，并不重新校准概率。不要据 holdout 反复调参。

### 分类权重、SHAP 与展示边界

分类 Marker 为逐组对其余组的正则化逻辑回归系数排名，并非拟合其他模型预测的代理解释。
每折仅在训练折拟合标准化，符号稳定性为各折与全数据拟合权重同号的比例；这不是生物重复层面的显著性。
各模型提供留出集混淆矩阵（计数/行归一化显示切换及完整下载），LDA 同样适用；完整报告记录种子、划分方式、实际折数和训练/测试细胞。
SHAP 提供类别解释、蜂群、单细胞瀑布、依赖图和全局重要性；导出完整张量、输入值、基准值及观察 ID。
逻辑回归线性解释器的输出为对数几率，树/模型概率解释为概率，瀑布图的基准和贡献必须在相同输出空间相加。
线性二分类解释原生正类，查看负类时对贡献及对数几率基准取反；跨类/细胞平均绝对贡献不表示方向或因果。
解释器的背景只从训练集抽取，展示细胞只从留出集抽取，随机种子与实际背景记录可追溯。

热图、细胞联动及论文导出操作见[网页流程](projects-and-data.md#图表作图数据和报告)，数值默认与阈值见[参数](#主成分marker-与热图)。

监督模型逐字段默认值与组合限制见[监督模型高级参数](#监督模型高级参数)。新报告保留请求值和展开默认值后的实际模型参数；PLS 另记录全训练集及各 CV 折实际潜变量数，含 SMOTE 后的训练数量限制。

监督页通过“新建训练 / 模型诊断 / SHAP 解释 / 下载与潜变量”定位；训练参数可展开或固定。诊断每次聚焦所选 ROC/PR/校准/混淆矩阵，完整报告按需展开；SHAP 每次展示所选图，完整贡献表仍可展开及下载。潜变量按钮“应用潜变量与训练/测试标识”只更新当前工作数据，不表示项目已保存。展开“监督高级参数”可调整所选模型；字段悬停显示内部键与约束，切换模型保留各自草稿。SHAP 的类别/细胞序号、精确特征 ID 及显示数量随项目保存，点击对应图按钮更新显示；解释计算仍须先训练模型。参数定义见[监督参数](#监督模型高级参数)。

#### 监督模型高级参数

网页“监督高级参数”按模型展示白名单字段；整数个数与小数比例严格区分，不能传入任意对象或代码。

| 模型 | 默认参数 | 组合约束 |
|---|---|---|
| 逻辑回归 | C=1、tol=0.0001、max_iter=5000、solver=lbfgs、penalty=l2、class_weight=balanced、fit_intercept=true、l1_ratio=null | C/tol 为正；L1 仅 liblinear/saga；elasticnet 仅 saga 且须设置 0–1 的 l1_ratio；liblinear 仅二分类；不正则化时 C 保持 1 |
| LDA | solver=svd、shrinkage=null、n_components=null、tol=0.0001、store_covariance=false | shrinkage 留空、auto 或 0–1；svd 不支持收缩；潜变量数不超过特征数和类别数减一，lsqr 仍不支持导出潜变量 |
| PLS-DA | n_components=2、max_iter=500 | 正整数；既有包装按各训练折实际细胞数减一和特征数限制潜变量数，报告另存实际值 |
| 随机森林 | n_estimators=500、max_depth=null、min_samples_split=2、min_samples_leaf=1、max_features=sqrt、bootstrap=true、class_weight=balanced、criterion=gini、max_samples=null | 树数 1–10000；树深留空或正整数；分裂/叶节点可用整数或小数比例，叶比例小于 1；候选特征支持 sqrt/log2/全部/个数/比例；max_samples 仅 bootstrap 启用时可用，须适用于最小训练折 |

随机森林的 `2` 表示两个细胞，`0.2` 表示训练细胞的 20%；`max_features` 的 `1` 表示一个特征，
`1.0` 表示全部特征。后端 Python/HTTP 还支持 LR/RF 的 `random_state`、RF 的 `n_jobs`；
网页种子来自监督训练字段，线程数沿用后端默认 -1，不混入实验控件。
新训练报告记录请求参数、展开默认值后的模型参数及 PLS 各折实际维数；历史只读报告不会补算这些字段。

SHAP 图的类别/细胞序号从 0 开始，特征使用精确内部 ID；显示特征数默认 20，范围 1–100。
显示设置与模型参数随项目保存；调整显示不重算解释、不失效模型，背景/解释数量改变仍会失效已有解释。
细胞降维已有控件覆盖 API 的现有显式字段：PCA whiten、UMAP 的内部 PCA/邻居/min_dist/metric、
t-SNE perplexity/learning_rate/max_iter，以及公共维数/缩放/seed；不开放任意底层构造参数。

## 时间与趋势

在“分析 → 伪时间与轨迹”中选择方法及新的独立输出键。Palantir 明确指定稳定细胞 ID 根点、
输入矩阵/层或已有嵌入；终末细胞可按行填写精确 ID，留空才由算法推断。少细胞时调整成分、近邻和路标，
点击“计算并应用时间结果”；检查实际根点、参数及结果表后，另选至少二维的显示坐标绘图。
不因选择输入或修改草稿自动计算，不覆盖已有键。

窗口轨迹明确选择坐标、时间列、含义和单位，可使用已算 Palantir 的伪时间和分支概率；
窗口/步长以细胞数计。时间列同名不表示含义相同，归一化采集进程不能当作小时。
不足有效细胞的窗口保留为空。计算失败保留原工作区；展示读取失败可重新读取，不要重复提交计算。

选择“窗口代谢速度”时，明确选择时间列、含义、单位和强度层（默认当前 X），不需要轨迹坐标或分支概率。
窗口至少 2 个细胞，计算各特征随递增时间的局部回归斜率，图显示速度向量范数；完整特征表保留正负方向。
相同时间窗口无有效回归，保留为空；这不是同位素示踪代谢通量，伪时间速度不代表物理时间速度。

选择“代谢物窗口趋势”时，显式填写时间列/含义/单位，选择强度层、精确特征 ID（空白使用全部）、
名称来源及 median/mean/sum 窗口统计，点击计算后检查实际参数及趋势表。
热图显示前 N 个排名特征，可开关“趋势显示行标准分”；两者只在点击绘图时更新显示，不重算或修改源数据。
缺失名称回退到 ID；全空窗口特征需结合有限细胞数解释，尤其 sum 的全空 0 不代表有效测量。

选择“趋势聚类”后，明确选择已有有效趋势作为来源，指定新输出键、距离和聚类方法；窗口统计不会重跑。
排名前 N 项留空使用来源全部特征，显式填写才取原排名子集；根据方法设置 seed、簇数、图近邻/分辨率或层次连接。
计算后检查生效参数、实际组数、无效 -1 特征和距离替代诊断，再独立绘图、下载完整结果或主动保存。
簇图灰线保留所有成员的标准化曲线，黑线为该簇均值；完整原趋势、标准化值、距离和特征分组均在 ZIP 中。
来源或依赖过期后旧聚类不可读取/导出；重开项目读取已保存数值及图，不重新拟合。

“选择命名时间结果”后可独立读取表、绘图或下载完整 ZIP。页面表至多 200 行，下载包含全部细胞、
分支、窗口和全部坐标维度及生效参数。点击“保存项目”才写正式快照；重开后读取已保存图或结果表不会重跑算法。
矩阵、细胞或相关时间/嵌入/分组依赖改变后，失效结果不可下载。当前同步上限与超时处理见
[时间分析参数](#网页时间分析参数)，算法与单位见[分析说明](#palantir-伪时间)。

### Palantir 伪时间

网页在“分析 → 伪时间与轨迹”中按稳定细胞 ID 指定根点，明确选择当前 X、强度层或已有嵌入。
输入表示直接用于扩散计算，不隐式选 PCA 或预先缩放；多尺度成分缩放由 `scale_components` 单独控制。
这与 [Palantir 扩散映射接口](https://palantir.readthedocs.io/en/latest/utils.html)的表示输入一致，
具体实现版本随结果记录。内部参考的 `PlotEngine` 示例中 `use_obsm` 只决定绘图坐标，计算仍使用 X，
不可据此推断网页输入。根点须来自实验先验；终末 ID 留空才由算法推断。

网页检查实际扩散核和缩放后的多尺度近邻图连通性，后者对照锁定 Palantir 的最短路输入构建；
任一断连都在算法补边前拒绝计算。
网页明确检查细胞量、有限输入、成分/近邻/路标范围。分支概率必须非负、逐行和为 1；
仅允许 `64 × float64 eps × max(细胞数, 分支数, 1)` 的上界及行和浮点误差，原值不裁剪或归一化。
记录所选根点、实际最早细胞、终末 ID、输入表示、参数、seed 和依赖版本。固定所选根点默认开启；
关闭时保留算法选择边界点的既有行为。伪时间是无量纲算法坐标，不解释为真实时间或因果方向。

每次计算独立命名，重复/失效旧键不覆盖；只在完整候选通过检查后一次应用。
读取、绘图、保存重开及下载均复用原数值。绘图坐标另选至少二维的已有嵌入，图中标出所选根点。
完整 ZIP 包含逐细胞伪时间/熵/全部分支概率、多尺度坐标与参数/分支名称/来源元数据；当前分析报告也收录有效结果。
持久化与失效边界见[命名时间结果](internal-reference.md#命名时间结果)，网页默认和工程上限见[时间分析参数](#网页时间分析参数)。

### 滑动窗口轨迹

网页明确选择坐标、时间列和时间含义：归一化采集进程（0–1）、采集秒数、自定义实验时间及伪时间。
导入的同名 `time` 列不自动解释；本服务产生的 Palantir 列必须声明为伪时间。
单位分别为 `unitless`、`s`、显式自定义单位和 `unitless`。不从显示行号猜时间。
窗口和步长以细胞数计，不是固定时长；排序沿用 NumPy `argsort`，完整导出保留实际排序位置。
窗口超过细胞总数时截断并记录请求/实际值，末尾不足步长时补最后一个完整尾窗。
分支键留空为单分支等权；显式指定但缺失/无效时拒绝，不沿用 Python 入口的静默单分支回退。
坐标或权重非有限的细胞不计入该窗口有效数；零权重细胞不贡献中心但仍计入有限细胞数。
不足最少有限细胞或权重和为零的窗口保留为空，图不跨空窗连线。
中心按全部坐标维度计算，图显示前两维。导出全部窗口的中心、时间、有效细胞数、权重和以及逐细胞输入/排序。
内部调用见[PlotEngine 时间方法](internal-reference.md#plotengine-时间方法)。

算法先按参数化列排序细胞，再在每个细胞窗口内计算低维坐标中心。若给定分支概率，会分别对
每个分支进行加权。

### 代谢速度

每个时间窗口内，对每个特征做强度随时间的一阶局部回归。所有特征斜率组成速度向量，其
欧氏范数作为总体代谢速度。结果在 `adata.uns["metabolic_velocity"]`：

- `state_centers`
- `velocity_field`
- `speeds`
- `time_centers`
- `counts`
- `window_starts`

如果窗口内所有时间相同，回归分母为零，该窗口无法产生有效速度。

网页在“分析 → 伪时间与轨迹 → 窗口代谢速度”复用同一算法，使用当前 X 或显式强度层，
按所选时间递增排序；每个特征斜率单位为输入强度/所选时间单位，范数保持该量纲。
正负斜率仅表示沿所选时间坐标的增减，不是同位素示踪代谢通量。归一化时间和伪时间的速度没有秒/小时含义；
不同强度层、归一化尺度、特征集和时间尺度的范数不能直接比较。
不足 2 个细胞或相同时间窗口保留未定义值，不插值、不跨空窗连线。
结果独立命名、输入身份复核、按时间依赖失效、主动保存及完整导出见[网页流程](#时间与趋势)。

### 代谢趋势

网页“代谢物窗口趋势”使用独立输出键，显式选择 X/强度层、时间列、含义/单位及精确稳定特征 ID（空白为全部）。
名称默认来自稳定 ID；可指定 `var` 列，缺失/空名称回退到 ID，重复名称保留 ID 区分；不存在的名称列拒绝。
网页与 Python 复用同一窗口池化、Spearman、BH 及排序算法，不改写 X、层或源趋势值；BH 只使用所选特征中的有限 p 值。
NaN 按原 reducer 忽略：全空特征窗口的 median/mean 为未定义，sum 沿原定义为 0；导出逐窗口/特征有限细胞数，
不能把该 0 当作有效测量。网页拒绝无限值及数值溢出，失败保留原工作区。
相同时间、常量趋势或不足 3 个有效窗口不产生可解释的相关/p/q，保留未定义值；有效窗口数也不是生物重复数。
重叠窗口有相关性，Spearman/BH 数值仅用于探索性排序，不作独立实验重复的显著性证据或时间因果推断。

网页热图默认显示排名前 30 个特征，并按每行有限窗口值做总体标准差的 z-score；常量行显示为 0，全空行仍为空。
可关闭显示标准化，显示原窗口统计量；横轴为递增时间排序的窗口序号，悬停和完整窗口表保留原始时间中心和单位。
显示数量和标准化独立于计算参数，重新绘图不重算趋势。全部特征统计、原窗口趋势及有限细胞数均可完整下载，
不受热图前 N 项或页面 200 行限制。伪时间、归一化采集进程与物理时间分别声明；不能把趋势当作代谢通量。

### 趋势聚类

支持的 `cluster_method` 为 `leiden`、`louvain`、`kmeans` 和 `agglomerative`，具体额外参数通过
`**kwargs` 传入。
相关距离适合比较曲线形状；欧氏距离同时受幅度影响。无法形成有限趋势的特征会标记为无效，
不应强制归入某个生物学簇。

网页“趋势聚类”只接受 TIME-03 的有效命名趋势结果，复用已计算窗口值，不重新计算趋势或改变 X/层。
与 `PlotEngine.plot_trend_clusters()` 一样，先按每特征窗口的有限均值及总体标准差标准化，再调用原四种聚类算法；
常量变为 0，含未定义窗口的曲线标为 -1，不强制归组。全空 sum 沿原统计得到 0，可能成为零曲线，必须结合导出的有限细胞数和有测量窗口数解释。
`top_k=null` 使用原特征顺序全部曲线；显式 N 才按原趋势排名选择，实际稳定 ID、来源结果 UUID 及参数一起记录。

距离仍为 correlation/cosine/euclidean/sqeuclidean。原距离辅助函数把未定义距离替为整个矩阵的最大有限值（包含对角线 0），
再置对角线为 0；常量相关/零向量余弦会触发该规则，结果显式记录替代对数，不把它当作已知生物距离。
KMeans 继续使用原 `n_init=20`、按 correlation/cosine 默认归一化（correlation 另中心化），并记录实际参数；
Ward 继续在标准化曲线的欧氏空间拟合，即使所选距离是平方欧氏，导出的所选距离矩阵也不能解释为 Ward 拟合目标。
其他层次连接使用所选距离，图聚类保留原 kNN 边、指数距离权重、Leiden RBConfiguration 或 igraph multilevel 定义，不切换到细胞图算法。
显式固定当前依赖的既有默认：Leiden 两次迭代、max_comm_size=0；Louvain resolution=1、return_levels=false，并写入生效参数。
请求簇数与 KMeans 实际簇数不一致时保留收敛诊断和实际组数。

网页 seed 默认 0；Leiden 通过显式 seed，Leiden/Louvain 另在独立短进程中设置私有 igraph 随机源，避免改变服务内其他分析的 RNG。
所有实际拟合在单并发短进程中执行，诊断随本任务返回，不修改服务的全局警告过滤器。
层次聚类无随机步骤，单个有效特征直接成组；二者实际 seed 记 null，保留请求值。记录 NumPy/SciPy/scikit-learn 及所用图依赖版本；
相同实现/依赖/seed 的本机合成重算核对与只读重载分别验证，不承诺跨版本标签编号一致。
每个簇图保留全部成员标准化曲线和均值；特征分组、原/标准化曲线、有限计数、完整所选距离表及时间窗口可下载，读取/重开不重新聚类。
来源结果或其时间/强度/名称/特征轴依赖失效时，聚类及图同样失效；分组仅是探索，不证明代谢通路、细胞命运或因果。

## 分析排错

### 降维与聚类

#### UMAP 报近邻数错误

`n_neighbors` 必须至少为 2 且小于细胞数。内部绘图层会调整该值，网页及统一 API 明确报错，需手动设置：

```python
n_neighbors = min(15, adata.n_obs - 1)
```

少于 3 个细胞不适合运行 UMAP。

若报 PCA 输入维数过大，网页 UMAP 默认使用 PCA 20 维输入；应在参数中明确减小维数或关闭 PCA 输入。
不同降维入口的默认值和处理边界见 [分析](internal-reference.md#统一降维入口)。

#### 缺少 Leiden/Louvain 依赖

```bash
uv sync --locked --all-extras --dev
```

然后重启开发解释器。项目声明的是 `python-igraph`；不要手工安装另一个同名 `igraph` 包。

#### UMAP 每次变化

- 固定 `random_state`。
- 固定输入矩阵、归一化顺序、PCA 维数和软件版本。
- 避免在 UMAP 前以不固定随机种子的异常值算法修改细胞集合。

即使固定随机种子，不同 UMAP/Numba 版本也可能产生数值差异，所以应归档环境定义。

#### 聚类主要反映文件来源

这可能是实验条件，也可能是批次效应。检查：

- 按 `label` 给 UMAP 着色。
- 比较每个文件的总强度、细胞数和检出率。
- 确认所有文件使用一致峰轴和处理参数。
- 在生物学解释前进行适合设计的批次评估/校正。

scMM 的 `alignwith()` 只做 m/z 对齐，不做批次校正。

### 时间轨迹与趋势

#### `time` 到底是什么

它通常是 0–1 的采集进程，不是实际小时。多文件情况下依赖文件采集时间戳；时间戳缺失时使用
文件修改时间，这可能受文件复制影响。正式时间分析应核对 `.meta` 中的时间来源。

#### 轨迹或趋势只有一个窗口

当 `WINDOW_SIZE >= 细胞数` 时只产生一个全局窗口。降低窗口大小和步长，并确保每个窗口仍有
足够细胞。

#### 代谢速度出现 NaN

- 窗口内参数化时间可能完全相同。
- 输入矩阵或时间列可能含 NaN/Inf。
- 窗口可能只有一个细胞。
- 离散组别编码不适合直接进行局部连续回归。

#### 趋势热图颜色和原始强度不一致

热图对每个特征沿时间做行内 z-score，显示相对升降趋势。原始池化强度位于：

```python
engine.adata.uns["metabolite_trends"]["pooled"]
```
