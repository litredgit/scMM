# 工作流程：网页与 Notebook

[文档索引](README.md) · [安装部署](installation.md) · [参数参考](parameters.md)

本页按实际操作顺序说明网页与 Notebook；精确默认值查参数参考，产物结构查 [数据与输出](data-output.md)。

| 入口 | 适用场景 | 保存方式 |
|---|---|---|
| Vue 网页 `scmm-web` | 多样本项目、提取审核、预处理与交互分析 | 主动保存项目，重载当前数据及预处理起点 |
| `scMM_workflow.ipynb` | 参数化分析、逐步检查及绘图 | 标准结果目录，分析对象需另存 H5AD |
| CLI / Python | 批处理、自动化与自定义流程 | 调用时指定输出，见[API](python-api.md) |

上述入口支持的原始文件为 mzML/mzXML 和 Thermo profile RAW（需外部 reader）。
参考离子必须按实验修改；不要把同一采集的 RAW/mzML 对照同时当作独立样本。

## Vue 网页：项目与样本

`scmm-web` 使用 Vue 前端和 FastAPI 后端，同源提供页面和接口；启动与构建见
[安装部署](installation.md#vuefastapi-网页)。

先用管理员创建的账号登录；首次登录或重置后须设置自己的密码。团队共享全部项目和指定原始数据，
各标签页工作区绑定当前用户，不能访问其他成员的未保存状态。管理员负责账号、全局预设和永久清空回收区。
登录默认最长 12 小时、无操作 60 分钟过期；后台心跳和任务轮询不延长用户操作有效期。
过期后停止新操作，不自动保存或重放写请求；同一账号重新登录时仅尝试连接仍有效的原工作区。
退出或改密前请主动保存；已提交的持久提取任务继续运行。账号初始化见[安装说明](installation.md#服务器初始化与账号)。

1. 在项目首页创建项目，或搜索并打开已保存项目。原有项目无需转换。
2. “项目与样本”页添加服务器白名单内的原始文件；文件浏览支持目录切换、搜索、分页和跨目录选择，
   也可展开直接输入路径。切换存储根时清空文件选择。选择一个样本及一个原始文件可重新定位。
3. 项目名称和说明填写后点击“应用项目信息”；样本 name/group/subject/batch 在输入结束后自动应用。
   name 必须非空且唯一。CSV 以 name 匹配现有样本，仅支持 name/group/subject/batch。
   样本信息同步当前数据及恢复起点，依赖变更字段的分析失效；移出样本不删除原始文件。
4. “导入已有结果”支持 H5AD 和不含 pickle 的结果目录；网页拒绝 pickle，旧结果请先离线转换。
   导入替换当前工作数据；无样本清单时按结果建立，关联不明确时选择来源字段并填写映射表。
5. 在页顶或“结果与保存”页主动保存项目。完整当前数据、恢复起点及已有只读报告沿用原子快照格式；
   另一个会话已保存时报告冲突，不覆盖其修改。

每个标签页持有独立工作区；刷新、关闭、新建或打开其他项目会放弃本页未保存修改，不弹出确认。
网页每 30 秒保持工作区连接；超过一小时无请求的工作区会过期，服务重启也会释放内存工作区。
重新连接只新建空工作区，需再次打开已保存项目，不自动恢复未保存修改。
失败操作显示错误；修订冲突时可“刷新状态”重取本页后端状态，此按钮不等于刷新浏览器。

当前六步网页提供 SDF 候选注释及天然同位素标记，保留测量峰；Python/Notebook 的旧删峰接口及尚未接入的时间分析
见[入口区别](analysis.md#vue-尚未接入的分析能力)。
[发展计划](roadmap.md)尚未实现的控件和后台任务行为不作为本页的现有操作说明。

### Vue 六步操作

项目与样本设置完成后，左侧按顺序进入以下页面。步骤切换保留本标签页的表单和图形，
项目保存才写入磁盘；原始参数草稿须先点击应用，分析页当前设置随“保存项目”写入。
六步页底部统一提供“上一步 / 下一步”；第一步可返回项目首页，最后一步只提供返回分析。
未建立当前数据集时禁用进入预处理/分析的下一步，并显示原因；执行操作期间禁用步骤按钮。
切换步骤本身不应用参数、启动计算或保存项目。左侧显示样本数、提取批次状态、是否已有数据和项目保存状态；
“可使用”只说明已有当前矩阵，不代表已完成预处理或科学验收。提取状态在其他工作流页面定时刷新，读取失败保留错误提示，
状态可能滞后于后台任务；进入提取页可刷新批次核对。顶部保存状态只代表项目的已应用修改，不代表原始参数草稿已生效。

页面以大屏桌面为主要布局，保留六步自由切页；窄屏流程导航横向滚动，“流程与账号”展开管理和参数参考入口。
账号菜单提供退出登录，顶部保留保存和关闭项目。错误与成功提示随滚动保留在可见位置。
AI 助手在宽度至少 1200px 的桌面展开时占用独立侧边空间；手机展开为独立面板，收起后回到工作流。

1. **原始谱与参数**：选择样本并打开文件，查看 TIC、多 EIC、快速网格或高分辨率合并谱、单扫描。
   单扫描支持帧号、时间、时间滑块及上一/下一帧，定位当前 MS level 的最近扫描。
   TIC/EIC/细胞窗口图可选择“选择合谱范围”并横向拖选；也可填写 RT 起止值，切换合并谱后更新。
   提取参数默认只显示 `ref_mz`、`mz_min`、`mz_max`、`cell_snr`、`cell_min_signal`、`feature_snr_threshold` 和 `max_zero_frac`。
   `cell_min_signal` 默认 `1e5`；每个扫描点须同时通过倍数条件和最低净信号条件，0 关闭附加条件。
   旧项目缺少该参数时保留为 0，使用前可显式调整；定义与边界见[最低净信号](parameters.md#细胞逐扫描最低净信号)。
   点击“展开全部参数”，在参考与范围、细胞与噪声、合谱与对齐、样本合并、计算资源及参考预设之间切换；
   常用项始终可见，切换分类或收起不会丢失草稿，也不会应用参数。`feature_merge_ppm` 仅在 independent 策略下显示。
   数值输入按内容留宽，m/z 上下限并排，参考离子列表及预设 JSON 使用整行；窄屏自动换行。
   显示范围与提取范围分开，合并谱可选择求和或平均。图形为显示适度下采样，完整 CSV 保留计算精度。
   参考离子预设位于提取参数区，须按实验明确选择并点击“使用所选参考离子”。选择“应用范围”后点击“应用参数”，
   可应用为项目默认（保留已有样本例外）或仅当前样本；“清除样本例外”回到项目默认及自动范围。
   合并策略、合并容差及自动范围始终是项目级设置，即使选择仅当前样本也会应用这些设置。
   状态区分别比较表单与所选应用范围、当前样本的正式提取参数；预览使用表单，正式提取使用已应用配置。
   保存项目不隐式应用提取参数；应用参数后也须主动保存。大屏左侧参数、右侧谱图，原始文件详情按需展开。
   全局参考预设由管理员主动保存，
   不追溯改变旧项目。参数解释悬停查看，完整定义见[参数说明](parameters.md)。
2. **细胞预览**：点击“预览细胞窗口”，使用当前表单参数在独立进程计算，页面轮询阶段状态。
   预览不建立当前数据；参数、样本、文件或项目配置改变后旧结果不应用。每工作区只允许一个预览。
   已开始的预览不能立即取消，刷新页面不能接回它；完成的有效缓存可在后续处理复用。
3. **提取与审核**：先检查参数与输入，可查看逐样本参数并下载预检 JSON；“开始提取”自动重新预检，
   保存输入配置并启动持久批次。关闭页面不停止批次，重新打开项目后可查看状态、失败与完整日志。
   停止只阻止后续样本。重试校验冻结输入身份、参数和成功产物摘要；文件改变或旧批次缺少身份时新建批次。
   已有批次时优先显示项目任务、阶段进度和审核区，“处理准备”默认收起，展开后可新建或重试；
   尚无批次时优先显示处理准备。审核区查看已完成样本的完整细胞信号，选择成功样本比较 QC，再点击“建立当前数据集”；
   没有人工纳入前不建立或替换当前数据。
4. **预处理与 QC**：支持过滤、七种归一化、插补和离群细胞移除；细胞图直接展示，当前来源文件 QC 明细按需展开。
   “检查影响”在候选副本计算，优先显示数据规模，各样本细胞数按需展开，来源文件 QC 指标默认展开并列显示操作前、候选后及变化；QC 图在宽屏并排、窄屏上下展示。检出特征数最多显示 1 位小数；“应用到当前数据”重新验证并提交，失败保留原数据。
   修改操作参数清除影响预览；页顶“历史与恢复”可展开并定位历史层及完整预处理起点恢复操作。矩阵变换使旧分析失效，历史层和处理记录保留。
   “注释与同位素”保留全部峰和强度，提供独立注释版本、规则导入、逐项核对及加合物筛选导出，见[下节](#注释与同位素)。
5. **探索与分析**：面板包含五种降维、五种聚类、差异与 Marker、相关网络、四种监督模型及 SHAP。
   公共图例与刷新入口集中为紧凑工具栏。宽度至少 1600px 时，降维、聚类、热图和相关网络以左侧计算参数、右侧图形组织；
   其余分析保留各自分区。所选细胞质谱位于模块之后，可清除选择。图形先展示，下载与论文导出设置位于图下方，PCA 解释率表位于嵌入图后。
   显式选择表示、图层、分组和随机 seed；已有嵌入/聚类键不能覆盖。着色可选元数据或特征，
   特征支持搜索、排序与分页。切换已有嵌入、着色来源或着色项时自动更新嵌入图，保留手动更新按钮；仅搜索/排序不重算嵌入。火山图点击可选择小提琴特征；隐藏零值只影响显示，不重做检验或 FDR。
   监督验证区分独立来源分组与细胞级探索，保留泄漏和重复数提示；LDA/PLS-DA 可保存支持的潜变量。
   修改科学参数使依赖结果和下载失效，重载的报告与图只读，SHAP/潜变量需重新训练模型。
6. **结果与保存**：页首先提供项目保存，随后提供“下载到本机”和服务器独立导出，大屏并列排列。
   项目快照路径、文件引用及 H5AD 保留说明按需展开。主动保存完整快照；下载当前矩阵、嵌入、QC、处理记录和有效分析报告，
   或单独导出当前 H5AD（拒绝覆盖）。上次快照 H5AD 不包含未保存修改。项目图形可重载查看并下载 JSON，
   每张图支持自定义文件名及 SVG/PNG 导出，图例位置独立保存。

项目首页和第六步均提供已保存项目/结果管理。按用途、所属项目、时间和大小识别内容，查看删除计划后点击“移入回收区”；
系统重新检查引用、活动工作区和任务。共享回收区支持恢复或永久清空，详见下方[保存和离开](#保存和离开)。
Vue 的独立导出默认选择项目结果存储，可显式选择目录和文件名；目标路径在执行前显示。
原始打开、分析和保存通过 HTTP 请求等待完成，同一工作区串行写入；这些操作不提供独立后台任务或 ETA。
未应用表单不会自动保存，服务更新前必须保存并关闭工作区。运行入口配置见
[安装部署](installation.md#开发与生产分离)，整体验收与生产切换记录见 [CHANGELOG](../CHANGELOG.md)。

## 网页：六步项目流程

完整操作见上方[Vue 六步操作](#vue-六步操作)；以下说明共同的保存、审核与结果边界。

### 注释与同位素

第五步分析页选择“注释与同位素”后，表单和结果直接显示，不需要展开外层卡片。
可先筛选细胞和特征，再按需注释；通常在归一化/插补前核对原始强度层。
页面使用分组表单及分类筛选/结果表，桌面横向组织筛选/表格，窄屏纵向排列；候选内部明细仍可折叠。

1. 检查数据库文件与版本。配置目录没有 SDF 时，“准备数据库”或首次运行从 LIPID MAPS 下载 LMSD；
   已有库校验后复用，损坏文件不会被静默替换。目录配置见[部署说明](installation.md#脂质数据库)。
2. 选择实际极性、加合物、注释质量容差，核对用于比例计算的未变换强度层和采集分辨率。
   所有容差内候选保留，精确质量只提供候选注释。参数及规则文件格式见[参数说明](parameters.md#网页注释与同位素)。
3. 可导入 JSON/CSV 评分规则，预览后由管理员保存为命名预设；也可选择已保存预设。没有自动启用的内置分值。
   本轮文献草案及完整分值见[规则文件夹](../rules/lipids/README.md)，安装包默认提供五份可选预设，名称带“审阅草案 v1”；选择后仍须运行或应用排序。
   点击“运行注释与同位素标记”生成独立版本，
   特征轴、矩阵、SNR 和已有数值分析保留。重复运行生成新的注释版本；“使用此注释版本”可切换或返回未注释状态。
4. 候选逐条显示，先按绝对 ppm 三档、再按网络支持等级、最后按档内规则分排序，同档同等级同分并列，不拼接名称。
   可逐特征选择候选并保存人工指定，或恢复规则推荐；导出“首档最高分及并列项”时，已有人工指定优先。
   天然同位素关系按候选来源及样本逐条展示，可接受、否定或恢复待核对；自动命中不删除峰。
   两张表分别选择排序条件与升降序，对全部结果排序后分页；缺失值最后。同位素样本按显示名排序，
   误差可选择绝对值或带符号值；候选组成先按排序后的首项排列，组内明细也使用同一顺序。
   显示排序不改写规则推荐、评分或人工指定；候选与关系 CSV 沿用各自排序，仍导出全部适用记录。
5. 显示/导出可组合类别层级、候选范围、同位素状态和加合物保留方式。三种加合物模式为全部、每种物质最强、仅指定。
   最强按各样本平均强度再等权平均，为全部细胞固定选择一列；只有相同物质 ID 或相同完整候选 ID 集合才归为一组。
   同分子式不直接合并，歧义分组不同的峰分别保留；强度相同按稳定 ID 决定固定列。未注释峰默认保留，可关闭。
6. 筛选矩阵 CSV 保留当前矩阵的完整数值精度及稳定特征 ID；候选明细按物质逐行输出名称/分子式/加合物/评分，
   完整同位素 CSV 保存母子关系及比例证据，可通过 feature ID 对应矩阵。下载不受当前特征或分页限制，
   同位素关系下载始终完整，以便审计隐藏的峰。用户筛选只作用展示和下载，不改当前矩阵。
7. 主动保存项目以保留版本、规则和核对进度，打开项目后可继续审阅和导出，无需数据库在线或重跑。
   修改评分只重排；细胞/特征、分组或强度来源变化使旧版本过期，过期版本不能下载。
   使用不变输入层时普通归一化不重跑注释；恢复完整预处理起点回到起点的注释状态，不是撤销最后一次人工选择。

#### 注释图表与相关网络

运行注释前可展开“相关性辅助注释与网络 · 高级参数”，核对原始输入层、相关方法、阈值、
样本范围及分子网络层；有明确重复分组时主动选择 `condition_field`，未设置时逐样本查看。
修改计算参数须重新运行新版本，不能套用旧版本证据。定义和限制见[分析说明](analysis.md#网页脂质候选与天然同位素)。

“注释分类与相关网络”显示特征数饼图及可切换的两种网络。先应用上方注释筛选，再选择分类层级、
网络、样本/条件，点击“应用图表显示”。高级显示参数提供正负边、节点上限、名称/mz 搜索及类别筛选。
点击节点在下方查看候选并人工核对，“展开邻居”只显示该节点及其相邻节点；再次应用图表显示恢复全图。
多义候选不进入分子合并；无歧义分子节点可指定代表离子或恢复自动代表。
边悬停和明细分别提供相关值、共同检出及化学关系，辅助证据表保留逐样本状态和重复共识。

可下载饼图/网络 SVG、PNG、计数表及完整节点/边 CSV、图表和证据 JSON、辅助证据 CSV。
节点上限只影响图片显示，表格和 JSON 导出不截断节点；注释筛选、搜索、类别和邻居范围仍适用。
两类网络的标题和导出注明强度层、方法、样本/条件。点击“保存图表设置”把显示参数及当前注释筛选
加入工作区，再主动保存项目；重开后恢复该设置。原始图表数据、逐样本证据和人工代表随注释版本保存，
无须在线数据库或重跑。人工候选/同位素审核更新标签、计数、支持等级及分子映射。

### 保存和离开

项目默认保存在 `~/data/results`，可用 `--project-root` 指定已存在的独立目录；原始文件只引用，不复制。
`--output` 不改变项目根目录。
以页顶“已保存 / 有未保存修改”为准。按钮直接执行，不使用确认复选框或二次确认弹窗；
新建、打开、关闭项目会放弃未保存修改，浏览器关闭或刷新也不弹出保存确认。需保留时先主动保存。
未应用的参数表单不属于已保存参数。没有新增自动保存或快照清理。

新建项目、提取批次、保存快照和 H5AD 默认名称包含北京时间，快照及 H5AD 带修订号；
H5AD 还包含项目名和已填写的样本批次标签。已有目录保持原路径，具体规则见[保存布局](data-output.md#当前网页项目保存)。
第六步可单独导出当前数据 H5AD，默认写入当前项目的 `exports/`；保存前显示完整目标路径，文件名可修改，拒绝覆盖。
“下载上次保存的 H5AD”另有文件名输入框，下载内容仍为上次项目快照，不包含未保存修改。

项目首页及第六步的“管理已保存项目、结果与回收区”可删除已保存项目、独立 H5AD 或已识别结果目录。
先保存并关闭相关项目；管理区默认不选待删除项目，可浏览选择具体结果，再查看实际路径、用途、文件数量和大小。
点击“移入回收区”直接执行；当前快照和完整恢复起点受保护，旧快照仍须通过引用与任务检查。
“导入已有结果”默认预选最后保存的可用矩阵，不自动导入；文件浏览默认收起内部产物，可勾选显示。
完整恢复请使用“打开项目”，避免把 `baseline.h5ad` 或逐样本提取文件误当作最终结果。
首页加载和未选择项目的刷新不会启动删除保护扫描；选择内容后的引用/任务检查可能随共享目录大小耗时。
系统重新检查内容身份、项目引用和未结束任务；原始谱、符号链接、存储根目录及其他环境的项目内容不能删除。
回收区支持恢复到原路径，不覆盖同名内容；父目录已删除时先恢复所属项目。
回收区由资源配置指定；已有部署可继续共用通用目录约定 `~/data/results/recycle`，不自动迁移旧条目。
移入回收区不释放磁盘空间；仅管理员可“清空回收区”，立即永久删除共享回收区内全部条目，不二次确认，无法恢复。
系统检查回收路径、符号链接、活动任务和引用；失败会报告未清理条目。原始谱引用不会移动原文件。

### 等待和排错

细胞预览通过当前会话接收结果；不能立即取消，也不支持刷新或重开页面后自动接回正在运行的预览。
关闭会话时尝试取消尚未开始的任务，已开始的计算会完成并释放进程；缓存完成不等于项目已保存。
每个会话只允许一个细胞预览，多个会话与提取批次之间尚无全局资源队列。
打开原始文件、分析和项目保存仍同步执行，等待期间不要重复点击或刷新。单扫描通过 HTTP 请求读取，连续选择时忽略过期响应。
“提取与审核”页显示批次状态、批次 ID、最近消息和失败详情，可下载完整任务日志；worker 日志持久保存。
提取页展示已处理/总样本、成功/失败/等待数、当前样本及阶段、已耗时与最近更新时间。
共同特征阶段按已合谱样本数、细胞特征提取按底层真实回调显示进度；读取、对齐、保存等无百分比阶段显示运行状态。
样本处理进度包含成功和失败，不能解释为成功率；旧批次缺少阶段字段时显示可用状态，不补造耗时。
审核时显示已选成功样本数，QC 对比及建集分别显示正在执行的操作。
批次运行状态不代表同步分析进度，也不是 ETA。

### 参数、审核与重试

项目共同特征策略为默认，独立选峰为高级选项；样本可设置参数例外，但共同特征相关参数必须一致。

每项目只能运行一批任务，尚无跨项目资源队列。纳入样本会建立/替换当前矩阵并清除旧分析，点击按钮直接执行。

单谱帧索引从 0 开始，RT 为秒；输入时间或拖动滑块定位到当前 MS level 的最近扫描，支持上一/下一帧。
打开样本后自动显示第一帧，选择时间/帧号或上一/下一帧后自动更新，不再需要显示按钮。
滑块松开后定位，读取请求合并短时间内连续选择，旧样本或旧帧的结果不会覆盖当前选择；加载及错误显示在单扫描图旁。
显示谱时同时呈现原生扫描标识。XML 可复用已加载实验；RAW 靠后单谱仍需顺序遍历。
TIC/EIC 和细胞时间图切换到“选择合谱范围”后拖选，或输入起止秒数，点击“更新合谱”；可切换求和谱/平均谱。
该范围只影响展示，不改变正式提取范围。

预处理先在副本验证再提交，失败不污染当前数据。矩阵变化使下游结果失效；新增嵌入不误删无关分析。
已有嵌入/聚类键不可直接覆盖，需使用新名称。保存模型报告不等于保存可执行模型，重载后如需操作须重新训练。
QC 表前三列 `source_file`、`reference_mz`、`cell_count` 按样本纵向合并并居中；文件列只显示文件名，悬停查看完整路径。
每个指标单独一行，统计列为 mean/median/std/min/max；cell_count 是样本实际细胞数，不是参考强度非空值数。
参考强度指标名称包含 m/z；不同参考离子保留独立行，仅省略该样本没有有效值的参考强度记录。
参考强度来自提取时的原始记录，不随当前 X 的归一化或插补重算；总强度和检出特征数反映候选矩阵。

任务信息在提取页查看，页顶错误可手动清除；完整日志可下载。
图形支持缩放与导出；保峰下采样只用于显示，CSV 保留本次计算结果。项目存储细节见[数据与输出](data-output.md)。

## Notebook：参数化流程

打开根目录的 [scMM_workflow.ipynb](../scMM_workflow.ipynb)，选择 `scmm` 内核。
常用配置集中在顶部 `parameters` 单元，其余单元通常无需修改。至少设置：

```python
from pathlib import Path

INPUT_PATH = Path("data/sample.mzML")
OUTPUT_ROOT = Path("results")
REF_MZ = 734.5929  # 换为实验参考离子
```

`INPUT_KIND="auto"` 按“受支持原始文件 → 含 .meta 的结果目录 → 原始目录”识别；
也可显式设为 `raw_file`、`processed`、`raw_dir`。目录不递归，按采集时间排序，
将输入视作连续采集并建立公共特征轴；不同实验条件可分别处理后通过 API 合并。

从头执行全部单元：检查参数 → 原始提取/载入结果 → 去同位素 → 异常值过滤 → 填补 →
归一化 → 可选 SDF 候选注释 → 保存 → 降维与时间分析。注释是精确质量候选，不能当作结构确证。
目录模式可用 `EXPORT_SUMMED_SPECTRUM` 导出总谱；详细开关见[参数参考](parameters.md)。

首次质控可明确采用以下配置（覆盖模板中的时间分析开关）：

```python
RUN_DEISOTOPE = False
IMPUTE_METHOD = None
NORMALIZATION = "total"
RUN_EMBEDDING = True
RUN_CLUSTERING = False
RUN_TRAJECTORY = False
RUN_METABOLITE_TRENDS = False
RUN_STABILITY_QC = True
```

检查细胞数、特征数、零值比例和嵌入后，再按需要开启聚类、去同位素、注释及时间分析。
已有结果重绘时设 `INPUT_KIND="processed"`，并关闭已经执行过的变换（例如 `NORMALIZATION=None`），
Notebook 不会自动推断处理历史。

`data.save(OUTPUT_ROOT)` 在输出根目录下创建数据集目录，默认不覆盖；明确替换时才设
`OVERWRITE=True`，它不会清空目录中无关文件。重新载入应使用实际数据集目录。
分析结果保存在内存 `engine.adata`，图写入 `FIGURE_DIR`；需要保留分析状态时另存：

```python
engine.adata.write_h5ad(output_root / "analysis.h5ad")
```

输出含义见[数据与输出](data-output.md)，异常处理见[排错](troubleshooting.md)。

## Vue 帮助与图形显示

参数、主要表头和辅助路径旁的圆形 `?` 提供说明，支持悬停、键盘聚焦与点击，Esc 可关闭。
参数名保留英文，说明注明单位、计算方向、边界和对当前数据的影响。预处理的 normalization
提供当前选项说明和全部方法列表；选择方法不执行计算，仍需点击检查影响或应用。
默认正文 16px，辅助说明 14px，标题统一为 20px/28px；按钮按功能区分：计算/应用蓝色、
保存/导出绿色、预览/检查紫色、恢复/停止橙色、删除红色，导航与展开使用中性色。

QC 的总强度和检出特征数均基于当前矩阵，检出定义为强度大于 0；参考强度保留提取记录。
`total` 后非零细胞总和约为 1，浮点求和可能产生约 10⁻¹⁶ 的差异。总和仅在精度误差范围内接近 1 时，
QC 使用稳定横轴范围，避免自动放大成多条竖列；零总和细胞保留在 0，实际数据和下载数值不变。
后续筛选、插补和其他变换可能再次改变总和；`log` 将零变为微小正值，`zscore` 的正值表示高于特征均值，
因此这些变换后的检出计数不再等同于原始峰检出数量。

图形按类型和容器宽度设置比例，谱图使用宽幅、ROC/PR/校准保持等比例坐标，小提琴图与 SHAP
按分面/条目数调整高度。SVG/PNG 下载保留当前显示比例，PNG 使用双倍像素。
QC 图例仅显示文件名，同名来源用短编号区分，悬停保留完整路径；窄屏的外置分类图例移到下方。

聊天历史恢复完成前禁用问题输入、快捷提问、发送及清空；恢复期间显示状态，切换工作区或登录用户后的旧响应不应用。
计算期间可提问，依据最近完成摘要的版本和时间解释；同步算法无细分进度时只报告正在运行的操作，
不给出百分比或 ETA。回答期间项目/数据/配置或登录状态变化会停止请求，已接收的过期部分标为不可继续沿用。
停止生成不保证服务商撤销已产生的计费；失败、限流或超时须手动重试，没有隐式重试。
精确质量注释只是候选，细胞数不等于生物重复，聚类分离不直接证明生物学差异；AI 建议仍须人工判断。

## 管理员监控

管理员从侧栏进入“管理员监控”（`/admin/monitor`）。页面独立于实验工作区，计算繁忙或工作区容量已满时仍可打开；
每 5 秒刷新当前状态，展示主机 CPU/内存/Swap、API 与计算进程资源、存储、最近 24 小时分钟均值/峰值趋势，
以及用户、工作区、持久任务、执行中的请求与安全事件。历史缺口与服务重启显示断线，采样失败保留旧值并标记失效。
CPU 合计以单核 100% 计；RSS 合计可能重复计算共享页。样本进度不等于预计完成时间。
监控只读，账号操作沿用“账号与管理”；不在监控界面取消任务、重启服务、配置路径或删除文件。

“当前实例”和“生产环境”分别检查，开发工作区不能代表生产。生产检查地址和运维凭据仅由管理员在仓库外配置，见
[安装部署](installation.md#监控初始化与生产只读检查)。旧版生产缺少页面登记协议时显示“无法确认”。

页面活动包括登录页、前台页面和后台标签页，每个浏览器文档独立登记，正常关闭/刷新时上报关闭。
20 秒心跳只更新页面证据，不自动延长登录会话或工作区寿命；实际键盘/指针操作与后台轮询分开记录。
超过 90 秒未收到心跳、浏览器休眠、崩溃或网络失联的页面标为“关闭待确认”，不能据此认为已关闭。
服务重启后已有登记继续保留，收到新心跳才重新确认；明确关闭的页面记录最多保留 24 小时。
未确认关闭的记录不会自动清除，以避免把失联用户误判为空闲。

只有所有业务页面已关闭、没有打开项目/未保存修改/繁忙工作区/活动任务/未完成业务请求，且采样完整新鲜，才显示“满足更新检查”。
已认证管理员的只读监控页单独计数；其关联工作区仍打开项目或繁忙时照常阻止更新。
检测到旧客户端未登记的业务请求也会显示无法确认；不要用 TCP 连接数为零代替页面关闭证据。
失联页面须先协调用户恢复连接并关闭；无法恢复时由管理员另行协调维护窗口，本界面不提供强制清除或绕过检查。
发布脚本会重新检查，页面上的结果不构成部署授权，也不保证检查之后不会有新页面进入。

### 论文图、细胞联动与热图

所有 Plotly 图提供 Nature（89/183 mm）和 Analytical Chemistry（84.6/177.8 mm）单/双栏预设，
可编辑宽高、字号及 DPI（常用 300/600/1200）；SVG/PDF 保留可编辑的二维矢量，PNG 按物理尺寸生成像素并写入 DPI。
三维场景可能包含栅格图层。白底、简洁坐标轴及色盲友好配色贯穿分析图；导出设置与网页可读字号分别控制。
期刊最终排版要求以 [Nature 图形指南](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/)
和 [Analytical Chemistry 作者指南](https://pubs.acs.org/ancham/pages/info-for-authors)为准。
“下载作图数据”提供 ZIP：图形 JSON、参数/来源 JSON、逐轨迹 CSV，以及适用的完整源表；不只保存显示抽样。
原始图、提取信号、QC、统计图、网络、SHAP 和热图均保留对应数值下载。过期数据关联的图需重新生成后下载。

提取审核页选择已完成样本可查看净信号、阈值、细胞窗口和编号；使用该批冻结的提取参数。
分析图中的细胞事件点可选入“细胞质谱”，最多两个，支持跨样本比较。
来源包括当前矩阵特征棒状谱、提取窗口求和/平均原始谱及峰顶单扫描谱；可切换原始/最大值/TIC 归一化，叠加/镜像。
原始来源需要有效扫描溯源及同一输入文件身份，缺少时明确提示选择矩阵谱。

热图可手填特征编号、使用所选特征、正向分类 Marker 或已注释特征；分组均值明确选择细胞等权或样本等权。
行/列聚类、分组注释条和行标准分仅改变图形；下载包含源矩阵、聚合矩阵、展示矩阵、注释和排序。
注释总组成候选如 PC(16:1/18:0) 和 PC(16:0/18:1) 折叠为 PC(34:1)，展开仍可逐条选择；不相加强度。
同位素表“查看截谱”按该关系的有效细胞显示局部平均特征谱，并叠加按母峰缩放的理论同位素峰；绿色框自动匹配、蓝色人工接受、橙色待检查、灰色人工排除，线型同步区分。
该证据图明确标为矩阵特征谱；原始谱可另从细胞联动查看。

### 管理员维护

账号与管理中可检查并暂存授权原始目录、项目结果、其他输出、缓存、临时及注释数据库目录，重启后加载，不迁移原始文件。
官方数据库更新保留旧 SDF、原始 ZIP、完整元数据、总组成候选汇总及校验来源记录。
维护按“收集全部会话 → 验证并暂存会话 → 重启/更新已批准版本”执行；收集期间禁止新增科学修改，
等待任务完成并要求每个页面确认草稿，失联/旧协议/快照或恢复校验失败会阻止执行。管理员可以取消维护。
恢复包括用户隔离的未保存矩阵、起点、结果、参数草稿、页面、图与选择、聊天和受审核的已训练模型。
更新入口只允许批准清单中的远端版本；重启失败恢复上一配置并进行健康检查。
