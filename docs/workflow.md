# 工作流程：网页与 Notebook

[文档索引](README.md) · [安装部署](installation.md) · [参数参考](parameters.md)

| 入口 | 适用场景 | 保存方式 |
|---|---|---|
| 网页 `scmm-ui` | 多样本项目、提取审核、交互分析 | 主动保存项目，重载当前数据及预处理起点 |
| `scMM_workflow.ipynb` | 参数化分析、逐步检查及绘图 | 标准结果目录，分析对象需另存 H5AD |
| CLI / Python | 批处理、自动化与自定义流程 | 调用时指定输出，见[API](python-api.md) |

三种入口支持的原始文件为 mzML/mzXML 和 Thermo profile RAW（需外部 reader）。
参考离子必须按实验修改；不要把同一采集的 RAW/mzML 对照同时当作独立样本。

## 网页：六步项目流程

1. **项目与样本**：创建或打开项目，添加服务器白名单目录内的 Thermo profile RAW、mzML/mzXML，
   填写分组、独立来源及批次。也可导入可信的已有结果/H5AD。
2. **原始谱检查**：打开样本，查看 TIC、多 EIC、合并谱、单扫描；应用参数，再运行细胞预览并确认。
   多 EIC 在一次谱遍历中计算，保持完整计算结果。细胞预览仍执行完整提取；靠后 RAW 扫描仍顺序读取。
3. **提取与审核**：检查实际参数，明确确认后提交。批次可在关闭网页后继续。
   “处理结束”不等于已建立当前数据：审核成功样本及 QC，选择纳入并建立当前数据。
   停止按钮仅请求停止后续样本，不立即中断当前读取/计算；已完成结果保留。
4. **预处理**：先检查影响，再确认应用。当前版本可恢复起点，不提供逐步撤销。
5. **分析**：按目的选择分析。每组单一来源时仅作细胞级探索，不把细胞数当生物重复数。
   参数改变后旧图可能保留作对照，但对应下载失效，须重新计算。
6. **结果与保存**：主动保存项目，然后下载所需产物。模型对象不保存，重载后报告及图为只读记录。

### 保存和离开

项目保存在 `/home/crs/data/results`；原始文件只引用，不复制。`--output` 不改变项目根目录。
以页顶“已保存 / 有未保存修改”为准。浏览器关闭或刷新时，对已进入项目状态的未保存修改尝试提示；
是否展示提醒受浏览器策略和交互条件影响，不保证移动端或异常退出时生效，也不替代主动保存。
未应用的参数表单不属于已保存参数。没有新增自动保存或快照清理。

### 等待和排错

预览、分析和项目保存仍同步执行，等待期间不要重复点击或刷新。右侧任务栏显示所选提取批次状态及完整
批次 ID；失败时提供 ID 和“下载完整任务日志”文件。操作记录仅保留当前会话，不能替代 worker 日志。
批次运行状态不代表同步分析进度，也不是 ETA。

### 参数、审核与重试

项目共同特征策略为默认，独立选峰为高级选项；样本可设置参数例外，但共同特征相关参数必须一致。
单样本失败后继续处理其余样本；重试复用成功产物和共同特征，科学参数改变时应新建批次。
每项目只能运行一批任务，尚无跨项目资源队列。纳入样本会建立/替换当前矩阵并清除旧分析，须确认影响。

原始谱的 m/z/RT 显示范围与正式提取范围分开；细胞预览使用完整提取参数与 MS1 扫描。
单谱索引从 0 开始，RT 为秒。XML 可复用已加载实验；RAW 预览会重读，靠后单谱需顺序遍历。

预处理先在副本验证再提交，失败不污染当前数据。矩阵变化使下游结果失效；新增嵌入不误删无关分析。
已有嵌入/聚类键不可直接覆盖，需使用新名称。保存模型报告不等于保存可执行模型，重载后如需操作须重新训练。

任务栏在宽屏常驻右侧，窄屏为可折叠浮层；错误需手动清除。日志显示末尾 30 KB，可暂停实时刷新、下载全文。
图形支持缩放与导出；保峰下采样只用于显示，CSV 保留本次计算结果。项目存储细节见[数据与输出](data-output.md)。

## Notebook：参数化流程

打开根目录的 [scMM_workflow.ipynb](../scMM_workflow.ipynb)，选择 `scmm` 内核。
常用配置集中在顶部 `parameters` 单元，其余单元通常无需修改。至少设置：

```python
from pathlib import Path

INPUT_PATH = Path("data/sample.mzML")
OUTPUT_ROOT = Path("results")
REF_MZ = 734.5929  # 换为实验参考离子
```

`INPUT_KIND="auto"` 按“受支持原始文件 → 含 .meta 的结果目录 → 原始目录”识别；
也可显式设为 `raw_file`、`processed`、`raw_dir`。目录不递归，按采集时间排序，
将输入视作连续采集并建立公共特征轴；不同实验条件可分别处理后通过 API 合并。

从头执行全部单元：检查参数 → 原始提取/载入结果 → 去同位素 → 异常值过滤 → 填补 →
归一化 → 可选 SDF 候选注释 → 保存 → 降维与时间分析。注释是精确质量候选，不能当作结构确证。
目录模式可用 `EXPORT_SUMMED_SPECTRUM` 导出总谱；详细开关见[参数参考](parameters.md)。

首次质控可明确采用以下配置（覆盖模板中的时间分析开关）：

```python
RUN_DEISOTOPE = False
IMPUTE_METHOD = None
NORMALIZATION = "total"
RUN_EMBEDDING = True
RUN_CLUSTERING = False
RUN_TRAJECTORY = False
RUN_METABOLITE_TRENDS = False
RUN_STABILITY_QC = True
```

检查细胞数、特征数、零值比例和嵌入后，再按需要开启聚类、去同位素、注释及时间分析。
已有结果重绘时设 `INPUT_KIND="processed"`，并关闭已经执行过的变换（例如 `NORMALIZATION=None`），
Notebook 不会自动推断处理历史。

`data.save(OUTPUT_ROOT)` 在输出根目录下创建数据集目录，默认不覆盖；明确替换时才设
`OVERWRITE=True`，它不会清空目录中无关文件。重新载入应使用实际数据集目录。
分析结果保存在内存 `engine.adata`，图写入 `FIGURE_DIR`；需要保留分析状态时另存：

```python
engine.adata.write_h5ad(output_root / "analysis.h5ad")
```

输出含义见[数据与输出](data-output.md)，异常处理见[排错](troubleshooting.md)。
