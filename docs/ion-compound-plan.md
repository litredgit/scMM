## 2. QE 分辨率与软件参数

### 2.1 已查证的仪器定义

Q Exactive 的分辨率设置以 m/z 200 为参考；经典 Q Exactive 的设置包括 17,500、35,000、70,000、140,000，
型号/选件不同不能混用其规格。Orbitrap 分辨率随 m/z 的平方根倒数变化：

```text
R(mz) = R200 * sqrt(200 / mz)
FWHM(mz) = mz / R(mz)
```

依据为 [Thermo Exactive 系列手册](https://documents.thermofisher.com/TFS-Assets/CMD/manuals/man-bre0012255-exactive-series-manbre0012255-en.pdf)
及 [Q Exactive 原始技术论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC3284220/)。
现有 `scMM/file/_spectrum.py::orbitrap_resolution_at_mz/orbitrap_fwhm_at_mz` 已实现这一缩放，优先复用，
统一网页细结构合峰代码的计算入口，避免第二套公式。

现有提取软件初始值是 `resolution=35000`。它可以从当前项目带入表单，但不等于已确认的实际采集值；
记录 `resolution_source=project_parameter|acquisition_metadata|user_input`，缺失时要求填写。
新功能不能按型号最大规格自动填写实际分辨率，不在未知时宣称能分开细同位素或重叠峰。

### 2.2 候选参数和决策参数必须分开

- 新归组 `search_ppm=5.0` 为基于用户经验的候选初始值；用户可显式切换到 10.0 或其他合法值。
  不自动放宽后把结果标作原来的 5 ppm 运行；提取原有 ppm 默认值保持原契约。
- `max_isotope_order=3`、`charge_magnitudes=[1,2]`（符号由极性和 IonSpec 决定）、同聚体默认目录到二聚体是软件候选搜索草案；
  自定义 IonSpec 支持其他合法电荷/聚合数，不暗示当前样品确有这些离子。
- 探索同位素证据可提供已有网页参数作为明确标注的草案：`min_valid_cells=20`、`isotope_relative_tolerance=0.2`；
  正负电荷、式量计算及样本划分属于硬约束，比例/相关/检出阈值属于可配置证据规则。
  草案不是实验推荐值，且只对有理论分布和合格线性输入的关系计算比例支持。
- 未知分子式的碳同位素序列可生成候选、推断电荷和保留包络；不得把纯碳近似当完整天然同位素分布。
  缺公式时没有理论比例证据，输出 `not_evaluable`，不以 0 分代替反证。
- 自动模式使用版本化 `exploratory_v1`，人工模式为 `reviewed_v1`。
  任何模式都要求完成的局部搜索、化学硬约束成立、来源有效、无未解决共享/混合定量冲突；
  `reviewed_v1` 另外要求相应人工关系接受和明确表示决策。
- 探索自动规则支持须明确列出逐样本通过/反证/不可评估，不能沿用“任一样本命中即全项目隐藏”。
  只在全部可评估样本无反证且满足所选规则时产生资格；全不可评估不自动接受。
  不同加合物比例变化本身不作为反证，也不以相关性单独建立关系。
- 代表选择排序固定为：合法完整来源及排除项检查 → 各样本等权检出率 → 各样本等权原始平均强度 →
  稳定 feature ID 破完全并列。人工指定也必须通过硬约束和适用范围检查，不跳过冲突报告。
- 不生成统一置信概率或 FDR。展示 `candidate/rule_supported/reviewed/ambiguous/rejected/not_evaluable` 等事实状态，
  记录规则、阈值、证据来源和人工例外；名称本身不表示经过校准的准确率。

### 2.3 两种模式的可执行资格表

“硬约束”指来源/轴/质量/元素组成/电荷/角色槽及实际共享混合等可判定条件，不把数据库未命中、
理论比例不可评估、相关性低或仅存在逻辑上的独立物质解释自动当作硬失败。
人工模式选择分组解释、接受关系及指定表示决策；未选软备选仍留存。没有公式、理论比例不可评估时，
人工接受可以产生 L1，只要其他硬约束和表示资格成立。人工接受不提升鉴定等级或证明信号纯度。

| 关系 | reviewed_v1 | exploratory_v1 | L1/L2 行为 |
|---|---|---|---|
| 天然同位素 | 人工接受关系与分组解释；质量/电荷/可分辨槽成立；无已记录未解决混合/共享冲突 | 需候选公式下天然分布比例支持；每个可评估样本满足20个有效细胞和相对20%草案、无反证、至少一个可评估样本；不同保留公式给不同结论则歧义；相关可选 | isotope_representatives 可排除合格子峰，保留一个固定观测代表；高阶峰不求和，M0不存在不补造 |
| 加合物/跨电荷 | 人工接受相容核心成员，全部共同质量区间及角色约束通过；不要求加合物比值恒定 | 需两端各有合格天然同位素包络支持、电荷相容、共同中性质量、无同资格成员竞争；否则只留候选 | 仅 ion_group_representatives 可排除额外离子；固定代表 L2 可用合格完整单体离子 |
| 同聚体 | 可人工接受为组关联，n与单体质量/电荷检查通过 | 仅候选关联，不自动产生排除资格；不以强度比例证明聚集响应 | 用户明确的组表示可保留单体代表并排除冗余显示列；聚集离子不作为本次默认L2代表 |
| 碎片/中性丢失 | 可人工接受有作用域的外链；有证据才报告支持来源 | 仅候选外链，不用于合并核心组 | 不自动排除、不充当桥、不作为本次L2代表；独立候选仍保留 |
| 未知/缺证据/单例 | 可保留并审阅，不能捏造缺失的硬约束信息 | 保留；全部not_evaluable不能变成自动通过 | L0/L1保留；单例仅在显式include_singletons时进入L2并标ungrouped |

完整搜索不等于消除一切 MS1 不确定性：按领域任务卡区分分组解释、角色配置、软备选与硬冲突。
自动选择只比较非任意证据层级：已接受直接实验关系支持 → 合格同位素包络支持 →
相容离子形式支持；同级且成员不同的解释保留 ambiguous，不用成员数、节点数、强度或 feature ID 决定归属。
仅 adduct/中性质量不同而成员及表示相同，可保留身份多解并接受成员关系。

L1的两种表示共用以上资格，isotope_representatives只去同位素冗余，ion_group_representatives
进一步使用已取得资格的核心离子成员；两者均完整交付，用户选择，不用同一名称隐藏不同变量含义。
L2自动选择优先合格完整单体离子；只有高阶天然同位素可用时可显式人工指定并保留阶数、干扰和覆盖限制。
源内碎片/多聚体只作为外链或附属成员保留，不因人工接受关系就自动成为本次化合物定量离子。

### 3.2 强制不变量

1. 仪器原始文件只引用；测量根不可覆盖。归组、注释和预处理不写回测量根。
2. Feature 使用 `(root_id, feature_id)`；关系、假设、EC、候选及视图使用独立 ID。m/z/名称/数据库 ID 不是跨根身份。
3. L0/L1/L2 不同变量轴用独立源视图；layers 仅表达同轴数值处理。L3 为关联信息，不强建已知物专用矩阵。
4. 同位素包络、离子组、定量表示和化学身份分别版本化；公式依赖和证据依赖可追溯，禁止隐式循环重算。
5. 同名、同公式、相同中性质量和数据库候选相同均不强制合并；竞争和未分辨信号可以长期保留。
6. 连通分量只分搜索区域；组内必须有共同可行质量区间和相容离子角色。碎片边不充当合并桥。
7. 不完整搜索的区域明确 unresolved，原候选和原特征保留；不能截断为 top-N 后声称唯一或完整。
8. 单个 feature 不重复用于两个可直接定量的 L2 变量。L2 全项目固定代表，未检出不切换离子。
9. 未检出 0 与结构性不可测分开。完整源 L2 可为 NaN+availability；旧分析工作区保持全有限要求。
   运行前显式预览并选择共同可量化的细胞/变量生成有限分析分支，空共同集报错，不静默补 0。
10. `raw`、baseline、重置不证明原始强度来源。线性/归一化/log/标准分/插补状态分开记录。
11. 原始谱图必须通过 member feature 回溯；EC 中性质量不得冒充实测 m/z。
12. 所有发布是完整候选校验后一次替换。过期请求、失败、取消、迟到 worker 不改当前项目。
13. 正式项目无可执行模型；维护包沿现有白名单及用户隔离保留模型，并逐分支验证数值。
14. 纯注释更新不改数值模型；标签/类别依赖图或解释需失效。元数据依赖按稳定 sample_id 传播到所有分支。
15. 正负极性按测量集明确区分；独立采集不按细胞序号一一拼接。

详细字段、签名、物化/激活顺序、NaN 规范化、生命周期、合并与引用闭包见[数据任务卡](ion-data-tasks.md)；
质量换算、角色槽、局部搜索、L1/L2、通用注释和证据反例见[领域任务卡](ion-domain-tasks.md)。
